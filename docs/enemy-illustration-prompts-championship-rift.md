## 1. 컨셉 개요 — 마족·핏빛·균열 차원

rift 컨셉은 챔피언십 5컨셉 중 **마계의 균열·마족·폭딜 차원** 환경. 클래식 챕터 4(마계의 균열)와 환경 카테고리는 같지만, 챔피언십은 4난이도 구조라 **각 난이도가 다른 마계 깊이**를 가진다. 게임 시스템 컨셉은 *폭딜·충격* — 적이 강한 헤비 공격 + 충격 게이지 부여 (100시 1턴 기절). 회피·방어로 막아야 함.

### 1.1. 모든 적 통일 컨셉

| 통일 키워드 | 의미 |
|---|---|
| **마족 종족** | 모든 일반/강적/보스는 마족 외형. 인간 비례 + 뿔/꼬리/검은 피부/송곳니/마계 색채. 또는 마수(4족)/거대 마왕 등 변주 |
| **핏빛-검은 톤** | 마족 신체는 검은 피부·핏빛 광채. 마계 갑주는 검은 강철 + 핏빛 룬 |
| **균열 차원 배경** | 모든 적 배경에 마계 균열·차원 균열·핏빛 안개 흔적. 단계가 깊을수록 차원 균열 강조 |
| **충격 시각화** | 무기·손마법에서 강한 폭렬 광채. 폭딜 컨셉 시각적 강조 |

### 1.2. 4단계 환경 톤

| 난이도 | 환경 단계 | 톤 |
|---|---|---|
| **1단계 (균열의 입구)** | **마계 첫 균열** | 인간 세계 경계가 갈라진 첫 균열, 핏빛-검은 안개, 차원 균열 입구, 부서진 인간 갑옷 잔해 |
| **2단계 (피의 전선)** | **마족 군세 진격 전선** | 핏빛 전선, 마계 핏빛 깃발, 부서진 인간 시신, 거대 마계 깃대, 짙은 핏빛 안개 |
| **3단계 (마계의 심장)** | **마계 중심부** | 마계 핏빛 결정 기둥, 마왕 옥좌 흔적, 거대 마계 룬 마법진 발치, 핏빛-검은 차원 |
| **4단계 (마왕의 영역)** | **마왕 절대 영역** | 마왕 절대 영역, 사방 거대 마계 균열, 차원 균열 핏빛 광채, 마계 룬 사슬, 거대 핏빛 결정 |

색조: **핏빛·검은·마계 보라** 톤. frost(청록·백청 빙설), forest(부패 녹·광기 보라·핏빛 꽃), sanctum(라벤더·황금 봉인 룬)과 명확 차별 — **마계 핏빛·검은 강철·차원 균열** 고유.

> forest도 일부 핏빛 사용하지만 *부패 광기 꽃·식물 톤* (꽃·잎). rift 핏빛은 *마계 폭력 신체·강철 톤* (마족 피부·마계 갑주). 색조는 비슷해도 *대상이 다름*.

### 1.3. 4보스 차별화 — 4가지 다른 마족 형태

**4보스가 "같은 마족의 색깔 변주"가 되지 않도록**, frost·forest·sanctum 12보스와도 **완전히 다른** 4종으로 분리:

| 보스 | 종족·스케일 | 자세·시전 양식 | 무기·도구 |
|---|---|---|---|
| **boss1 균열의 군주** | **마족 검사 (인간 비례 + 뿔·꼬리·검은 피부·붉은 눈)**, 마계 갑주 정교 | 양손검 휘두름 (지상 운동감, 균열 막 돌파) | **거대 핏빛 마계 양손검 한 자루** |
| **boss2 피의 전선 사령관** | **4족 보행 3머리 마수 (마계 사냥개)**, 거대 핏빛 갈기, 마계 갑주 | 4족 자세 + 다중 머리 으르렁 + 사방 위협 | **무기 X, 거대 핏빛 발톱·송곳니·갈기** |
| **boss3 심장의 마왕** | **공중 부유 마족 대마법사** (인간 비례 + 거대 마족 날개), 마계 두건·로브 | **공중 부유** + 사방 마계 룬 마법진 시전 (절대 정적 위압) | **무기 X, 양손 마계 룬 마법진 + 거대 핏빛 마법** |
| **boss4 마왕의 화신** | **거대 마왕 (인간 비례 X, 신적 스케일)**, 마계 균열에서 막 솟아오름, 거대 뿔·날개·꼬리 | **마계 균열을 깨고 솟아오름 (강한 운동감)** + 거대 도끼 휘두름 | **거대 핏빛 마계 도끼 + 마계 균열 차원 폭렬** |

차별화 검증 — **인간형 마족 검사 / 4족 다중 머리 마수 / 공중 마족 술사 / 거대 마왕** — 종족·다리 수·자세·무기·스케일 모두 다름. frost·forest·sanctum 어떤 보스와도 겹치지 않음.

## 2. 사용법

1. 각 코드 블록을 그대로 복사해 **ChatGPT (DALL-E 3)**에 입력 (1.53.0~ Copilot 폐기, ChatGPT 통일)
2. **반드시 클래식 챕터 4 일러 1장을 첨부**해서 화풍 통일도 (예: `public/enemies/classic/chapter_4/nakzelionShadow_intro.jpg`). 마계·핏빛 톤은 챕터 4가 가장 가까움
3. 한 번에 1~2장 생성 → 마음에 안 들면 같은 채팅에서 "더 OOO하게 다시" 멀티턴 보정 (ChatGPT는 보정 제어가 정확)
4. PNG 다운로드 → `public/enemies/championship/rift/chapter<N>/<enemyKey>_combat.jpg` 또는 `_intro.jpg` 위치에 저장 (forest·sanctum 패턴 그대로)
5. PM이 main에 푸시 → Claude가 git pull → Pillow로 JPG 변환 후 원본 PNG 삭제 + 헬퍼 rift 분기 추가 PR

`enemyKey`는 `src/data.js`의 `ENEMIES` 객체 키와 동일 (예: `champ_rift_imp`).

> ⚠️ DALL-E 3 안전 필터로 **폭력·잔혹·핏빛 묘사 거부 가능** — "다크 판타지 RPG 적 일러스트" 컨텍스트 강조. 거부 시 "선혈 X, 마계 광채로 대체" 멀티턴 보정.
