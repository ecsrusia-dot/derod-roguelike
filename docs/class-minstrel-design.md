# 광기의 악사 (Minstrel) 신규 직업 설계서

> **작성 시점**: 1.50.0 직후 (광기의 마녀 보스 승격 + 광기의 악사 normal 신설 직후)
> **상태**: 설계 단계 — PM 검토 + 마다듬이 후 구현 시작
> **결정 사항**: PM이 **음표·코드 시스템 (옵션 A)** 선택

---

## 0. 배경

1.50.0에서 `champ_forest_minstrel` (광기의 악사)을 forest_3 normal로 신설했으나, **일러스트 품질이 보스급과 양대산맥** 수준. PM은 일반 적으로 두기 아깝다고 판단 → **6번째 플레이어 직업**으로 격상 결정.

이 문서는 광기의 악사를 신규 직업으로 만들 때의 **메커니즘 설계 / 5직업과의 차별화 / 액티브·패시브·소울 스킬 / 각인 / 일러 / 구현 로드맵**을 사전 정리한다. 구현 PR 시작 전 PM이 보고 마다듬이.

## 2. 5직업 vs 광기의 악사 차별화 매트릭스

| 직업 | 자원 | 자원 누적 | 메인 루프 | 키워드 |
|---|---|---|---|---|
| 방랑검사 | 영혼 (0~100) | 회피 시 / 매 턴 | 영혼 100 → 소울 스킬 | 검·물리·반응 |
| 술법사 | 마력 (0~5) | 매 턴 +1 / 영혼 활용 | 마법 시전 + 재시전 | 마법·화염 |
| 혼혈 마족 | 광기 (0~10) | 자해 시 (HP 소모) | 광기 임계점 도달 시 폭발 | 자해·광폭 |
| 숲의 정령사 | 바람 | 회피 시 / 매 턴 | 정밀 사격 + 회피 | 활·정밀 |
| 여명의 사제 | 신앙 | 매 턴 / 패시브 | 회복 + 신성마법 | 회복·신성 |
| **광기의 악사** | **음표 (0~7)** | **매 턴 +1 / 사용 시 +1** | **2/3/5 임계 콤보 발동 + 7 충만 보너스** | **음악·콤보·조합** |

### 차별화 핵심 (n×n 비교)

| 축 | 검사 | 술법 | 마족 | 정령 | 사제 | **악사** |
|---|---|---|---|---|---|---|
| 자원 단위 | 0~100 (선형) | 0~5 (소형) | 0~10 (선형) | 0~? | ? | **0~7 (임계 콤보)** |
| 자원 누적 | 회피·매 턴 | 매 턴 | **자해** | 매 턴 | 매 턴 | **매 턴 + 사용 시** |
| 자원 소모 | 100 일괄 | 1~5 시전마다 | 임계 폭발 | 시전마다 | 시전마다 | **2/3/5 임계 콤보** |
| 콤보 시스템 | X | X | X | X | X | **★ 임계값 다단 발동** |

**→ 음표 임계값 다단 발동(2/3/5)이 5직업과 완전 차별화되는 유일한 특징**. 카드 게임의 콤보·조합 메커니즘 도입.

## 3. 핵심 메커니즘 — 음표·코드 시스템

### 3.1 음표 (Note) 자원

| 속성 | 값 |
|---|---|
| 범위 | **0 ~ 7** (7이 최대 충만) |
| 시작 음표 | 1 (지능 시그·각인으로 +N) |
| 매 턴 +N | **+1** (기본) — 패시브·각인으로 최대 +2 |
| 음표 사용 | 코드·멜로디·교향곡 시전 시 |
| 음표 7 충만 효과 | 다음 턴 자동 보너스 (패시브 기반 — 회피·치명·데미지) |

### 3.2 임계값 다단 발동

| 음표 사용량 | 발동 종류 | 효과 강도 |
|---|---|---|
| **2** | **코드 (Chord)** | 기본 효과 (단일 적 attack / debuff / buff 중 1) |
| **3** | **멜로디 (Melody)** | 강화 효과 (attack + 부가효과 1) |
| **5** | **광기 교향곡 (Madness Symphony)** | 최대 일반 효과 (attack + 다중 부가효과) |
| **7 + 소울 100** | **★ 소울 스킬 「광기의 종말 교향곡」** | 직업 소울 스킬 발동 |

### 3.3 음표 시각화

전투 UI에 음표 7슬롯 (보라 결정 아이콘) 표시. 충만 시 모든 슬롯 회전 광채.

```
[♪] [♪] [♪] [♪] [♪] [♪] [♪]     ← 음표 슬롯
[ON][ON][ON][OFF][OFF][OFF][OFF]   ← 현재 3개 (멜로디 발동 가능)
```

## 4. 액티브 스킬 5종

> **공통 규칙**: 한 직업 액티브 슬롯 5개. 첫 번째는 기본 스킬 (cost 0 / cd 0). 4번째는 소울 스킬 (음표 7 + 소울 100).

| # | 스킬 | 음표 cost | CD | 타입 | 데미지 | 부가 효과 | 컨셉 |
|---|---|---|---|---|---|---|---|
| 1 | **광기의 음** | 0 (기본 스킬) | 0 | sonic | 8-12 | 시전 시 **음표 +1** (자원 누적용 기본) | 류트 한 줄 튕김 |
| 2 | **광기의 화음 (코드)** | 2 | 0 | sonic | 14-20 | 적 광기 음파 디버프 1마디 누적 | 2현 화음 |
| 3 | **광기의 자장가 (코드)** | 2 | 2 | defense | 0 (defense+30) | 다음 1턴 받는 데미지 -25% + 적 봉인 가능성 ↑ | 적 매혹 |
| 4 | **광기의 멜로디** | 3 | 0 | sonic | 24-32 | 다음 턴 회피 +20% | 류트 솔로 |
| 5 | **광기의 교향곡 (Mass Symphony)** | 5 | 3 | sonic | 38-50 (heavy) | 적 모든 광기 디버프 +1마디 + 본인 음표 0 | 풀 오케스트라 |

> **소울 스킬은 별도 슬롯** (StatusPanel 4번째 슬롯, 음표 7 + 소울 100 발동)

### 4.1 소울 스킬 — 광기의 종말 교향곡 (Finale)

| 속성 | 값 |
|---|---|
| 발동 조건 | **음표 7 + 소울 게이지 100** |
| 데미지 | 대규모 광기 음파 폭격 (적 HP 30% 일괄 + 50-70 추가) |
| 부가 효과 | 적의 광기 음파 디버프 마디 수만큼 추가 데미지 (×10 / 마디) → 5마디 = +50 |
| 본인 효과 | 음표 0 + 다음 1턴 무방비 (자해 컨셉, HP 보호) |
| 일러 | UltimateCutin — 류트가 거대 광기 결정으로 전환 + 보라 광기 음파 풀스크린 파동 |

> "광기의 정원을 들이쳐, 모든 광기를 한 곡에 담아 휘몰아치는 마지막 교향곡"

## 5. 패시브 7종 × 7Lv

> **공통 규칙**: 한 직업 시작 패시브 7개. 각 7Lv까지 강화. Lv5에서 부가 효과, Lv7에서 각성 스킬 보상 1개 선택 (ULTIMATE_SKILLS).

| # | 패시브 | 핵심 효과 | Lv5 부가 | Lv7 각성 후보 |
|---|---|---|---|---|
| 1 | **음표 증폭 (Note Amp)** | 매 턴 음표 +1 → **+2** (Lv7) | 음표 누적 시 보너스 데미지 | 「영원의 곡」 — 음표 최대치 7→9 |
| 2 | **광기 화음 (Mad Chord)** | 코드 시전 시 데미지 +N% (Lv별 5/10/15/20/25/30/35%) | 코드가 단일 적 추가 데미지 | 「화음 폭주」 — 코드 시전 시 광기 음파 +1마디 |
| 3 | **광기 멜로디 (Mad Melody)** | 멜로디 시전 시 데미지 +N% (동일 강화) | 멜로디 시전 후 음표 +1 | 「영겁의 선율」 — 멜로디 시전 시 회피 +50% (1턴) |
| 4 | **광기 음파 (Mad Sonic)** | 적 광기 음파 디버프 마디 효과 강화 (마디 1당 -5% 회피 → -10%) | 광기 디버프 5마디 도달 시 폭발 데미지 | 「광기 해방」 — 디버프 폭발 시 본인 음표 +3 |
| 5 | **일곡일목 (Once a Song)** | 음표 7 충만 시 다음 턴 보너스 (회피·치명·데미지 중 1) | 충만 유지 시 매 턴 추가 보너스 | 「영원의 충만」 — 음표 5 이상 유지 시 보너스 활성 |
| 6 | **광인의 영감 (Madman's Muse)** | 적 처치 시 음표 +1 (Lv7: +2) | 보스 처치 시 음표 +N | 「광인의 환생」 — HP 0 도달 시 1회 광기로 부활 (HP 30%) |
| 7 | **광기 교향곡 (Mad Symphony)** | 광기 교향곡(5음표) 시전 시 데미지 +N% (Lv별) | 교향곡 시전 후 음표 +2 | 「종말 교향곡」 — 교향곡 시전 시 소울 게이지 +50 |

> **Lv별 시그니처 (Lv1·3·5·7)**: 각 패시브가 Lv1에서 기본, Lv3에서 강화, Lv5에서 부가, Lv7에서 각성 후보 선택.

### 5.1 시작 패시브 분배

> 다른 직업처럼 시작 시 **Lv2~3 패시브 1~2개** 부여. 광기의 악사는:
> - **음표 증폭 Lv3** (기본 자원 시스템 작동)
> - **광기 화음 Lv2** (코드부터 사용 가능)

## 7. 데미지 타입: `sonic` (신규)

기존 데미지 타입 (`physical` / `magic` / `defense` / `buff`)에 `sonic` 추가.

| 데미지 타입 | 색상 | 컨셉 | 비고 |
|---|---|---|---|
| physical | PALETTE.accent | 검·물리 | 방랑검사 |
| magic | PALETTE.twilight | 마법 | 술법사 |
| defense | PALETTE.ice | 방어 | 공통 |
| buff | PALETTE.dawn | 자기 강화 | 공통 |
| **sonic (신규)** | **#a594d8 (광기 보라)** | **음파·음악** | **광기의 악사 전용** |

데미지 계산은 `magic`과 유사 (지능·마력 영향) 또는 매력 시그니처 영향 — PM 결정 필요.
