## 핵심 수치·공식 (원작)

- **치명타 데미지** = 원래 데미지 × (100% + 저격%) × 2
- **명중/회피/피해감소/받아넘기기 상한 95%** (내성은 상한 없음)
- **추가:독** = 적 최대 HP의 3% → 6% → 9% (중첩 단계별)
- **한계돌파 캡**: 기본 9,999 → +0: 99,999 → +2: 999,999 → +4: 9,999,999 (방벽 9→99개)
- **합리주의** = 위력 × [1 + 0.25 × (효과 개수 − 1)]
- **스킬 레벨**: 같은 스킬 재습득 시 상승, Lv.3·Lv.8 추가 효과, 만렙 8
- 스킬 플래그: T=턴 미소모 / B=방벽 소모 / F=선제공격
- 스킬 숨은 등급 A~D (수상한 나그네는 B등급 이상 전수)

## 방 색깔 (원작) — 정벌·재앙 보스 결정

우선순위 빨강→녹색→파랑→보라→노랑→하늘→검정. 색 효과: 빨강 피해+15% / 녹색 쿨-1 / 파랑 보호막+15% / 보라 방벽 발동+25% / 노랑 회복+15% / 하늘 쿨+1.
가장 많이 방문한 색이 보스를 결정 (예: 빨강=린드브룸/발록, 파랑=자하크/다키니).

## 직업 70종 (미이식 — 각색 후보 상위)

구조: 유니크 패시브 1 + 고정 패시브 2 + 기본 스킬 3. 해금: 마석 구매 / 이벤트 4회 조우(성녀·용기병·다크엘프) / 시즌.

| 원작 직업 | 유니크 패시브 (각색 가치 높음) |
|---|---|
| 마검사 | 혈류 — HP 소비 스킬마다 영구 강화 +50% (25중첩) |
| 흡혈귀 | 최대 HP 절반, 매 턴 25% 회복 |
| 페어리 | HP 1 고정(정신체) + 방벽 필발동(2개 소모) |
| 암흑기사 | 방벽 많을수록 위력↑ |
| 강령술사 | 보호막 획득마다 방벽 +1 |
| 하플링 | 회피 다음 턴 확정 치명 |
| 애벌레 | 피해 10회 → 우화, 공격 2배 |
| 사무라이 | 버프 효과 +25% (복리) |
| 도굴꾼 | 층마다 장비 성능 재조정 |
| 이계의 존재 | 피해가 HP에 안 닿음, 보호막 0 = 사망 |

## 이벤트·기타 (참고)

- 묘비/샘/석상: 영구 보너스(행운+5, 위력+5%, HP+100)와 함정(폭발 30%, 독가스, 석화)이 한 테이블 — 1.107.0에서 각색 이식
