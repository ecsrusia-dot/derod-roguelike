## 1. 컨셉 개요

forest 컨셉은 챔피언십 5컨셉 중 **부패·숲·광기** 환경. 클래식 챕터 2(죽은 자의 숲)와 환경 카테고리는 같지만, 챔피언십은 4난이도 구조라 **각 난이도가 다른 환경 단계**를 가진다. 게임 시스템 컨셉은 *광폭/자해* — 적이 매 턴 자신에게 공격력 +N 누적 (시간 끌수록 강력).

| 난이도 | 환경 단계 | 톤 |
|---|---|---|
| **1단계 (입문)** | **시든 외곽** | 황혼 외곽숲, 시든 황갈색 잎, 죽어가는 거대 나무, 안개에 묻힌 가지, 부패 시체 흔적 |
| **2단계 (망자의 길)** | **망자의 길 부패숲** | 더 깊은 부패숲, 뒤틀린 나무 통로, 망자의 시체와 부서진 갑옷이 길에 깔림, 짙은 부패 녹 |
| **3단계 (광기의 정원)** | **광기의 부패 꽃밭** | 광기의 마녀가 빚어낸 거대 광기 꽃 정원, 보라-핏빛 꽃 안개, 광기 결정이 가지에 매달림 |
| **4단계 (광기의 종막)** | **부패 신경 심부 + 광기 음악 무대** | 거대 부패 뿌리가 신경처럼 얽힌 가장 깊은 심부 동굴이 광기 음악 무대처럼 솟음, 신적 봉인의 시네마틱 스케일 + 광기 음파 회전 |

색조는 단계가 올라갈수록 점진 변화: **시든 황갈·녹회·옅은 보라(1단)** → **짙은 부패 녹·뼈색·짙은 갈색(2단)** → **부패 보라·핏빛·광기 꽃(3단)** → **검녹·부패 보라·신적 봉인 광채(4단)**.

### 4보스 차별화 — 4가지 다른 존재 형태

**4보스가 "같은 인물의 색깔만 다른 변주"가 되지 않도록**, 그리고 frost 4보스(인간 전사 / 거대 거인 / 사룡 / 무형 망령)와도 **완전히 다른** 4종으로 분리:

| 보스 | 존재 형태 | 자세 카테고리 | 무기·전투 양식 |
|---|---|---|---|
| **boss1 시든 자들의 어머니** | **하반신이 거대 뿌리·시든 꽃과 일체화된 모성 정령** (인간 X, 식물 융합) | 양팔로 시든 자식들을 끌어안는 모성 위협 (포용·돌출) | 무기 X, 손바닥에서 솟는 거대 뿌리·가시 |
| **boss2 망자의 군주** | **부패 갑옷 망자 검왕** (인간 시체 전사) | 거대 부패 양손검 광폭 휘두름 (수평 운동감) | 거대 부패 양손검 한 자루, 마법 X |
| **boss3 광기의 마녀** | **광기 비술 인간 여성 마법사** (정상 인간 비례, 광기 마녀 모자·로브) | 지팡이 들어올린 광기 시전 + 손바닥 광기 폭렬 마법진 (절제된 광기 미소) | 광기 마녀 지팡이 한 자루 + 광기 폭렬 손마법진 |
| **boss4 광기의 종말 마에스트로** | **광인 음유시인 마에스트로** (인간 남성, 광기 보라 톤, 정상 인간 비례, 광기 류트 마에스트로 양식) | 양손으로 11현 광기 류트 연주 자세 + 광기 음파 회전 (정밀 광기 연주) | **11현 광기 류트 한 자루** (부패 원목 + 광기 결정 박힘) + 광기 보라 음파 발산 |

→ **식물 융합 정령 / 부패 인간 시체 전사 / 광기 비술 여성 마법사 / 광인 류트 마에스트로** — 종족·실루엣·자세·무기·시전 양식 모두 다름. boss3 = *마법진 손마법 시전자*, boss4 = *광기 음파·음악 시전자* (마법진 X, 류트 연주). 둘 다 인간형 시전자이지만 무기(지팡이 vs 류트) + 시전 방식(마법진 vs 음파)으로 명확 차별. frost의 인간 전사/거인/사룡/망령과도 모두 다름.

> **1.50.2 변경 사유**: 기존 boss4 컨셉(거대 다중 머리 키메라 신)이 일러스트 미생성 + 광기의 악사 직업 구현 보류로 일러스트 1장이 남음 → PM 결정으로 악사 일러를 forest_4 최종 보스 일러로 승격 활용. 보스 컨셉을 *광기 류트 마에스트로*로 전면 재설계. 4보스 종족·자세·무기 4축 차별화는 재검증 완료(위 표).

## 2. 사용법

1. 각 코드 블록을 그대로 복사해 **Microsoft Copilot Designer**에 입력
2. **반드시 클래식 챕터 2·4 일러 1장을 첨부**해서 화풍 통일도 (예: `public/enemies/classic/chapter_2/twilightChild_intro.jpg` 또는 `public/enemies/classic/chapter_4/nakzelionShadow_intro.jpg`). 부패·숲 톤은 챕터 2가 가장 가까움
3. 결과 4장 중 가장 잘 나온 1장 선택. 마음에 안 들면 같은 채팅에서 "더 OOO하게 다시" 멀티턴 보정
4. PNG 다운로드 → `public/enemies/championship/forest/<enemyKey>_combat.jpg` 또는 `_intro.jpg` 위치에 저장
5. PM이 main에 푸시 → Claude가 git pull → Pillow로 JPG 변환 후 원본 PNG 삭제

`enemyKey`는 `src/data.js`의 `ENEMIES` 객체 키와 동일 (예: `champ_forest_husk`).

## 3. forest_1 — 시든 외곽 (입문, 5종 + 보스 진입 1종)
