## 2. PM 요청 → 설계

### 2.2. 판정과 비전투 보상 (요청 1)

- 선택지 판정 = 능력치 + 주사위 ≥ 난이도. 라벨: 확실 / 유리함 / 보통 / 불리함 / 도전적
- 성공 보상: **경험치** · 은화 · 아이템(낮은 확률) · 명성 — 전투 없이도 성장
- 명성은 성공한 능력치 계열로 쌓임 → 「검술로 알려지는 중 (2/4)」 → 별호·엔딩 방향 결정

### 2.3. 스킬 3등급 (요청 2·4) — 오리지널 판타지

모든 스킬 = **발동 조건 1개 + 관련 능력치 1~2개**. 위력·회복량 = 기본치 × (1 + 관련 능력치 × 계수). **전투당 각 1회**, 나머지는 평타.

| 등급 | 획득 | 예시 (스킬 / 조건 / 관련 능력치) |
|---|---|---|
| **일반** | 시작 커스텀에서 3개 선택 · 일반 몹 사건 · 상점 | 질풍 걸음 / 상대가 회피하면 / 민첩 · 철벽 자세 / 처음 공격받으면 / 강인 · 응급 처치 / HP 40% 이하 / 신성 · 화염구 / 첫 턴 / 마법 · 견제 사격 / 적 대공격 예고 시 / 사격 · 급소 찌르기 / 적 HP 30% 이하 / 검술+통찰 |
| **고급** | 강적 승리 후 이야기 + 판정 · 상점(드묾) | 폭풍 베기 / 3턴째 / 검술+근력 · 관통 화살 / 적 방어 시 / 사격 · 연쇄 번개 / 적 회피 직후 / 마법 · 성역 / HP 50% 이하 / 신성 · 피의 갑주 / 처음 치명타를 맞으면 / 강인 |
| **기연** | 보스 승리 후 이야기 + 판정 · 우연한 기연 사건 | 검성의 일섬 / 적 HP 50% 이하 / 검술 · 용의 숨결 / 전투 시작 / 마법 · 천궁의 화살비 / 3번째 회피 후 / 사격+민첩 · 여명의 기적 / 쓰러질 때 1회 부활 / 신성 |

### 2.4. 습득 개연성 (요청 4)

습득 성공률 = 기본 성공률 × **적성 계수**(스킬의 관련 능력치가 내 빌드에서 차지하는 비중).

| 예시 | 결과 |
|---|---|
| 검술·근력 빌드가 검술 기연을 만남 | 성공률 높음 |
| 검술·근력 빌드가 대마법사의 기연을 만남 (마법 0) | **극악 (약 3%)** — 서술: 「주문이 머릿속에 들어오지 않는다」 |
| 유니크 장비 | 같은 방식 — 장비의 관련 능력치와 빌드가 맞아야 다룰 수 있음 |

선택지도 랜덤이지만 **빌드 방향과 맞는 선택지가 더 자주** 등장하도록 가중 → 처음 정한 육성 방향을 끝까지 밀면 클리어가 유리.

### 2.5. 상점·경제 (요청 5)

| 항목 | 설계 |
|---|---|
| 진열 | 스킬·장비를 **랜덤 3~4개만**. 리셋 **1회** |
| 등급 | 일반~고급만 (기연·유니크는 상점 불가) |
| 경제 | 은화 수입 대폭 하향 · 가격 상향 → 한 생에 핵심 구매 1~2번 수준 |
| 드랍률 | 현재 일반 승리의 70%가 무언가를 줌 → 장비 위주 **약 10%**, 스킬은 전투 드랍 없음(이야기·판정으로만) |

### 2.6. 장비

무기 / 방어구 / 장신구 3칸. 장비에 능력치 보너스(원작 「귀면갑: 힘 +1, 외공 +2, 통찰 +1」 방식). 등급: 일반 / 고급 / 보물 / 유니크.

### 2.7. 전투 태세 (PM 확정)

| 태세 | 효과 | 비용 |
|---|---|---|
| 평상 | — | 없음 |
| 투지 개방 | 공격·회피 ×1.2 | 없음 (전투당 HP 소모 소량) |
| 생명 연소 | ×1.5 + 보호막 | **생명의 불꽃 1** (한 생 3개) |
| 한계 돌파 | ×2, 체력 희생 | **생명의 불꽃 2** |
