## 사용 가이드

1. PM이 카페·인스타 계정을 만든 직후 `cafe-introduction.md`·`instagram-profile.md`를 **고정글·프로필 자기소개**에 그대로 복붙
2. 직업 소개 시리즈는 주 1회 페이스로 1~5편 순차 발행 (5주)
3. 게임 일러·전투 컷은 `public/classes/`·`public/enemies/` 폴더에서 직접 다운로드
4. 본문 안의 게임 빌드 정보(시작 패시브·스탯·소울 스킬 등)는 `src/data/classes.js`·`src/data/passives.js` 기준 — 게임 버전이 올라가 데이터가 바뀌면 본 문서도 갱신 필요
