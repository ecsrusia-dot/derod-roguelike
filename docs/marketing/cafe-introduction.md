### **게임 소개 — 던앤트와일라잇은 어떤 게임인가요?**

> **한국어 텍스트 기반 다크 판타지 모바일 로그라이크**

| 핵심 키워드 | 설명 |
|---|---|
| **로그라이크** | 매번 새로 시작하는 1회성 모험. 죽으면 다시. 단, 영혼은 영구히 쌓입니다 |
| **텍스트 기반** | 화려한 3D 대신 글로 그리는 다크 판타지. 한 컷의 일러스트와 한 문장의 묘사로 분위기를 만듭니다 |
| **다크 판타지** | 황혼·서리·부패·봉인·균열·여명 — 무거운 톤의 6가지 챕터 컨셉 |
| **모바일 PWA** | 설치 불필요. 브라우저로 즉시 실행. 홈 화면에 추가하면 풀스크린 앱처럼 동작 |
| **5직업 × 6챕터** | 방랑검사·술법사·혼혈 마족·숲의 정령사·여명의 사제. 각자 다른 빌드 |

### **운영 약속**

- **모든 글·댓글에 가능한 한 직접 답변합니다.**
- 버그 제보는 가장 우선순위 — 빠른 핫픽스로 대응합니다.
- 패치 노트는 인게임 모달과 함께 카페에도 동시 업로드합니다.
- **유저 의견을 실제 게임에 반영합니다.** 직업 밸런스·UI 개선·신규 콘텐츠 결정에 카페 의견을 적극 참고합니다.

### **첫 시작이 어렵다면**

게임 첫 진입 후 **튜토리얼 4단계** 부터 차근차근 진행해보세요. 노드 타입 7가지 → 상점/대장간 → 분기 선택/천리안 → 저주 시스템 — 게임의 모든 기본을 학습하는 구조입니다.

튜토리얼 4를 클리어하면 **수련의 길 5직업**이 모두 해금됩니다. 그때부터는 본인이 좋아하는 직업으로 자유롭게 모험할 수 있습니다.

## PM 사용 팁

- 본문 끝의 *"플레이 링크"* 자리에 실제 GitHub Pages URL 삽입
- 본문 상단·중간에 직업 일러 1~2장 첨부 (`public/classes/wanderer.jpg` 등) — 시각적 임팩트

- 카페 메인 화면 배너에는 5직업 일러를 가로로 합친 이미지 추천 (PM이 별도 합성)
- **첫 게시 시점에 인스타에서도 "카페 오픈 안내" 포스트로 동시 푸시** — 양 채널 시너지
