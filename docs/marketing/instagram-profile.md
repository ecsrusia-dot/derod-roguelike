## PM 사용 팁

### 포스트 발행 페이스

| 요일 | 콘텐츠 | 비고 |
|---|---|---|
| 월 | 직업 소개 (격주) | 5주에 걸쳐 5직업 |
| 수 | 게임 컷·일러 단일 (적·유물·전투 컷) | 시각 위주 |
| 금 | 개발 일지·짧은 카피 (스토리·세계관·운영 후기) | 친밀감 |
| 주말 | 자유 (밈·반응·유저 빌드 리포스트) | 가볍게 |

> 처음에는 **주 3회**부터. 부담되면 주 2회로 줄여도 OK.

### 카드뉴스 vs 단일 이미지

- **카드뉴스 (캐러셀 5~10장)**: 직업 소개·시스템 설명에 적합. 인스타 알고리즘 우대
- **단일 이미지**: 빠른 푸시·시각 임팩트에 적합

> 직업 소개는 무조건 **카드뉴스 5장 이상**. 알고리즘에 노출 잘 됨.

### 해시태그 전략

- 한 포스트당 **20~25개** 권장 (인스타 한도 30개)
- 게임 핵심 태그(5개) + 장르 태그(5개) + 한국 인디 태그(5개) + 분위기 태그(5개) + 트렌드/대중 태그(5개)
- 카피 본문 끝에 한 줄 띄우고 모아서 노출 (—— 구분선 권장)

### 스토리 활용

- 게시물 업로드 후 **스토리에 즉시 공유** (피드 노출 보강)
- 카페에 새 글 올렸을 때 스토리로 1~2장 캡처해서 안내
- 개발 중인 일러스트 작업 과정 등 비공식 콘텐츠 — DM 친밀감 ↑

### 첫 1개월 KPI 가이드 (참고용)

| 지표 | 1개월 목표 |
|---|---|
| 팔로워 | 50~100명 (인디 첫 달 평균) |
| 평균 좋아요 | 10~30 |
| 평균 도달 | 200~500 (해시태그 노출 기준) |
| DM·댓글 | 5~10 (질문·반응) |

> **숫자에 매몰되지 마시고** — 첫 1개월은 콘텐츠 톤·페이스 안착이 더 중요합니다.
