## 0. 조사 범위와 신뢰도

스토어 페이지는 세션 네트워크 차단으로 열람 불가. 공개 소개문 + 장르 관례로 분석.

| 구분 | 원작 운용 방식 | 신뢰도 |
|---|---|---|
| 시작 | 죽은 주인공이 시골에서 깨어남, 회귀 능력 보유 | ✅ 소개문 |
| 성장 | **본 기술을 한눈에 익히는 눈** | ✅ 소개문 |
| 진행 | 사건 해결 · 인연 · 명성 | ✅ 소개문 |
| 목표 | 최종전 승리 | ✅ 소개문 |
| 회귀 | 죽으면 처음으로, **전생의 비밀 → 다음 생 기연의 열쇠** | ✅ 소개문 |
| 시간 | 한 생에 날짜 제한, 행동이 곧 기회비용 | ⚠️ 장르 관례 추정 |

**원작의 본질**: 회차를 거듭하며 강해지는 건 수치보다 **플레이어의 기억(지식)**.

## 1. 컨셉 — 「회귀의 탐험가」

| 항목 | 설계 |
|---|---|
| 세계관 | 황혼이 대륙을 삼키기까지 **40일**. 탐험가는 죽을 때마다 **여명의 마을**에서 다시 눈뜬다 |
| 주인공 | 본편 5직업 중 택1 (방랑검사·술법사·혼혈 마족·숲의 정령사·여명의 사제) |
| 무대 | 본편 4지역 그대로 — 북부 극지대 / 죽은 자의 숲 / 봉인된 신전 / 마계의 균열 |
| 목표 | 41일째 **황혼의 첨탑** 공략 (4연전 보스 체인) |
| 시그니처 능력 | **기록자의 눈** — 전투에서 본 적의 기술을 기록해 내 것으로 (원작 명칭 미사용) |
| 회귀 | 사망 또는 첨탑 패배 → 1일째 마을로. **기억 조각** 계승 |

## 2. 운용 루프

```
[여명의 마을에서 눈뜸] → [40일 탐험: 하루 1행동] → [41일 황혼의 첨탑]
        ↑                       │ 사망                     │ 승리 → 엔딩
        └────── 회귀 ───────────┘ (기억 조각 · 기록 1개 계승)
```

### 2.1. 하루 행동 (1행동 = 1일)

| 행동 | 효과 | 재사용 화면 |
|---|---|---|
| 🧭 탐험 | 현재 지역에서 전투 1회 (일반/강적 선택) | **`CombatScreen`** |
| 📜 사건 | 지역 사건 진행 (선택지·판정·연쇄) | **`EventScreen`** |
| 🗺 이동 | 다른 지역으로 (1일, 균열은 2일) | 신규 지역 지도 |
| 🤝 교류 | 동료 호감도 + (해당 지역에서만) | 신규 대화 화면 |
| 🏕 야영 | HP 회복 · 스킬 재선택 | **`RestScreen`** |
| 🛒 거래 | 마을·지역 상인 (주 1회 입고) | **`ShopScreen`** |

### 2.2. 지역 4곳 (본편 데이터 재사용)

| 지역 | 본편 기믹 그대로 | 기록 가능 계열 | 위험도 |
|---|---|---|---|
| 북부 극지대 | 혹한 (3턴마다 양측 HP -5) | 방어·반격 | ★ |
| 죽은 자의 숲 | 부패의 안개 | 독·출혈 | ★★ |
| 봉인된 신전 | 봉인의 잔향 | 봉인·마법 | ★★★ |
| 마계의 균열 | 마기 폭주 (+10%) | 흡혈·폭발 | ★★★★ |

→ 적·일러·기믹 **전부 기존 데이터** (클래식 챕터 1~4 일러 100% 완성분). 신규 일러 필요 = 첨탑 최종 보스 1장 (없으면 기존 폴백).

## 3. 핵심 시스템

### 3.1. 기록자의 눈 — 적 기술 습득 (모드 정체성)

| 단계 | 규칙 |
|---|---|
| 기록 | 적이 패턴(공격·버프·대공격)을 쓸 때마다 그 적의 **기록 게이지** +(15 + 지능 시그니처 보정)% |
| 대공격 보너스 | `heavy` 패턴을 **간파 카운터**(방어/회피/기절)로 받으면 게이지 2배 |
| 습득 | 100% → 그 적에 연결된 **패시브 +1Lv** 또는 **액티브 스킬 해금** |
| 장착 | 본편 그대로 — 액티브 3칸 + 소울 스킬 1칸, 패시브 Lv |
| 진열 | 도감처럼 「기록서」 화면에 적별 게이지·보상 표시 |

적 → 기록 보상 매핑 예시 (본편 `PASSIVE_SKILLS` / `COMBAT_SKILLS` 재사용):

| 적 (지역) | 기록 보상 |
|---|---|
| 얼음 늑대 (극지) | 패시브 「정밀」 +1 |
| 동상 거인 (극지 강적) | 액티브 「방검」 해금 |
| 극지의 망령 | 패시브 「심안」 +1 |
| 숲 강적 | 독 계열 패시브 +1 |
| 신전 강적 | 봉인 계열 액티브 |
| 균열 강적 | 흡혈 계열 패시브 |

→ **"이길 수 있는 적"보다 "기록할 가치가 있는 적"을 고르는 판단**이 재미 포인트. 강적은 위험하지만 게이지가 크다.

### 3.2. 명성 (첨탑 자격)

| 명성 | 해금 |
|---|---|
| 30 | 지역 강적 출현 |
| 60 | 상위 사건·동료 3단계 |
| 100 | **황혼의 첨탑 입장 자격** (미달 시 41일째 패배 처리 → 회귀) |

획득: 전투 승리 +3 / 강적 +8 / 사건 성공 +5~15.

### 3.3. 동료 인연 (MVP 4명, 오리지널)

| 동료 | 만나는 곳 | 해금 보상 | 인연 엔딩 |
|---|---|---|---|
| 떠돌이 치유사 | 숲 | 야영 회복 ↑, 벨트 포션 +1 | 은둔의 숲 |
| 몰락한 기사단장 | 극지 | 방어 계열 액티브 전수 | 기사단 재건 |
| 균열의 정보상 | 균열 | 숨은 사건 위치 공개 | 그림자 시장의 주인 |
| 신전 기록관 | 신전 | 첨탑 보스 패턴 공개 | 봉인 수호자 |

호감도 0~100, 3단계 (안면 → 동행 → 맹약). 맹약 동료는 **첨탑 전투에서 1회 지원**.

### 3.4. 회귀 메타 — 계승 규칙

| 계승 O | 계승 X |
|---|---|
| 🧩 **기억 조각** — 비밀·단서 플래그 (영구) | 레벨 · 명성 · 호감도 · 골드 |
| 📖 **기록 1개** (회귀 시 택1, 게이지 50% 상태로) | 나머지 기록 · 유물 |
| 🗝 **기연** — 기억 조각 조합 시 새 사건 개방 | 벨트 포션 |
| 📕 회귀 도감 (동료·기록·엔딩) | — |

기억 조각 예시: "3생에서 18일째 신전 함정에 죽음" → 다음 생 그 사건에 「전생의 기억」 선택지 등장 → 함정 회피 + 봉인 단서.
수치 계승은 최소화. 회귀 1회당 **시작 HP +5** (상한 +50)만.

### 3.5. 황혼의 첨탑 (최종전)

본편 마스터즈 **`bossChain`** 패턴 재사용 — 라운드 사이 회복 없음, HP 이월.

| 라운드 | 상대 | 비고 |
|---|---|---|
| 1 | 한기의 마녀 (강화) | 극지 보스 재사용 |
| 2 | 죽은 자의 숲 보스 (강화) | 기존 보스 |
| 3 | 봉인된 신전 보스 (강화) | 기존 보스 |
| 4 | **황혼의 첨탑 주인** (신규) | 2페이즈. 기억 조각 3개 이상이면 정체 공개 → 약점 개방 |

### 3.6. 엔딩 (MVP 5종)

첨탑 정복 엔딩 1 + 동료 인연 엔딩 4. 엔딩 도달 시 칭호 + 도감 기록.

## 4. 본편 재사용 매핑 (UI = D&T 오리지널)

| 필요 기능 | 재사용 | 신규 작업 |
|---|---|---|
| **전투** | `CombatScreen` 그대로 (AP·의도·heavy·소울·벨트·자동 사냥·배속) | 적 패턴 사용 시 기록 게이지 콜백 1개 추가 |

| 야영·상점 | `RestScreen` · `ShopScreen` | — |
| 정보창 | `StatusPanel` | — |
| 적·일러·기믹 | `ENEMIES` 챕터 1~4 · `chapters.js` gimmick | 첨탑 보스 1종 |
| 보스 연전 | 마스터즈 `bossChain` | — |
| 공통 UI | `CommonUI.jsx` 토큰·부품 | 날짜 진행 화면 · 지역 지도 · 기록서 · 동료 대화 |

신규 화면은 **날짜 허브 · 지역 지도 · 기록서 · 동료 대화** 4개뿐. 나머지는 본편 화면.
