| 구분 | 내용 | 신뢰도 |
|---|---|---|
| ✅ 확인 | 장르 = 무협 **텍스트 로그라이트 RPG** (어드벤처) | 소개문 |
| ✅ 확인 | 죽은 주인공이 **시골에서 깨어남** → 회귀 능력 보유 | 소개문 |
| ✅ 확인 | **본 무공을 한눈에 익히는 눈**(원작 명칭 「천무지안」) | 소개문 |
| ✅ 확인 | 사건 해결 · **인연** 맺기 · **이름(명성)** 드높이기 | 소개문 |
| ✅ 확인 | 목표 = **무림맹 최종전 승리** → 낭인 → 별호 고수 → 맹주 | 소개문 |
| ✅ 확인 | 죽으면 처음으로 회귀, **전생에 발견한 비밀 → 다음 생 기연의 열쇠** | 소개문 |
| ⚠️ 추정 | 한 생에 **시간 제한**(일/턴 단위)이 있고 최종전 날짜가 고정 | 장르 관례 |
| ⚠️ 추정 | 행동 = 수련 / 이동 / 사건 / 교류 중 택1, 스탯 성장 | 장르 관례 |
| ⚠️ 추정 | 전투는 텍스트 자동 진행 + 무공 선택 | 장르 관례 |

## 1. 원작 운용 방식 분석 — 핵심 루프

```
[시골에서 눈뜸] → [N일 동안 행동 선택] → [무림맹 최종전]
      ↑                  │ 사망                    │ 승리 → 엔딩
      └──── 회귀 ────────┘ (기억·단서 일부 계승)
```

| 축 | 원작 운용 (확인+추정) | 플레이어가 느끼는 재미 |
|---|---|---|
| **시간** | 최종전까지 날짜 한정 → 모든 행동이 기회비용 | "이번 생에 뭘 포기할까" 선택 압박 |
| **무공 습득** | 상대가 쓴 무공을 **보는 것만으로** 습득 | 강적과 싸울수록 강해짐 → 일부러 강자에게 도전 |
| **인연** | 인물과 관계 → 사건·무공·동료 해금 | 회차마다 다른 인물 루트 |
| **명성** | 이름을 알려야 상위 사건·최종전 자격 | 성장의 가시적 지표 |
| **회귀** | 죽음 = 실패가 아닌 **정보 획득** | 전생 지식으로 다음 생 최적화 (로그라이트 핵심) |
| **비밀·기연** | 한 생에 못 푼 비밀 → 다음 생 열쇠 | 회차가 쌓일수록 숨은 루트 개방 |

**원작의 본질 한 줄**: "강해지는 건 캐릭터가 아니라 **플레이어의 기억**" — 회차 간 계승은 수치보다 **지식·단서** 위주.

## 2. 우리 모드 컨셉 — 「윤회강호」

| 항목 | 설계 |
|---|---|
| 세계관 | 던앤트와일라잇 세계의 **동방 강호** (황혼이 강호에도 드리움) — 본편과 별개 모드 |
| 주인공 | 무명 낭인 1인 (본편 5직업 미사용, 무덤의 유산·제령사처럼 **완전 분리**) |
| 한 생 | **60일** (MVP) → 61일째 **강호맹 대회합(최종전)** |
| 목표 | 대회합 4연전 승리 → 「맹주」 엔딩 |
| 시그니처 능력 | **견식안(見識眼)** — 전투에서 본 무공을 **간파 게이지**로 습득 (원작 명칭 미사용) |
| 회귀 | 사망 또는 대회합 패배 → 1일째로. **기억 조각** 계승 |

## 3. 시스템 상세

### 3.1. 하루 행동 (1행동 = 1일)

| 행동 | 효과 | 비고 |
|---|---|---|
| 🧘 수련 | 스탯 1종 +2~3 | 장소별 보너스 스탯 다름 |
| 🗺 이동 | 지역 변경 (1~2일 소모) | 지역 5곳 |
| 📜 사건 | 지역 사건 1개 진행 (선택지·판정) | 연쇄 이벤트(본편 `chain` 패턴 재사용) |
| 🤝 교류 | 인물 호감도 +, 인연 단계 해금 | 인물이 있는 지역에서만 |
| ⚔ 비무/토벌 | 전투 → 명성 + **견식** | 강한 상대일수록 간파량 ↑ |
| 💤 휴식 | 내상·HP 회복 | 내상 = 다음 전투 패널티 |

### 3.2. 스탯 5종

| 스탯 | 역할 |
|---|---|
| 근골 | HP · 외공 위력 |
| 내공 | 내공 위력 · 무공 사용 횟수 |
| 신법 | 회피 · 선공 |
| 오성 | **간파 속도** (견식안 핵심) · 사건 판정 |
| 명성 | 사건·인물 해금 게이트 · 대회합 참가 자격 (명성 100 이상) |

### 3.3. 견식안 — 무공 습득 (모드의 정체성)

| 단계 | 규칙 |
|---|---|
| 간파 | 적이 무공을 쓸 때마다 해당 무공 간파 게이지 + (10 + 오성/2)% |
| 습득 | 게이지 100% → 「초식」으로 습득 (위력 60%) |
| 숙련 | 직접 사용할수록 숙련 → 「성(成)」 단계 5단계, 위력 60→100%→130% |
| 장착 | 무공 슬롯 **4칸** (외공 2 · 내공 1 · 신법 1) — 많이 배워도 4개만 |
| 상성 | 외공 / 내공 / 독 / 암기 4계열 — 적 계열별 상성 |

→ **"이길 수 있는 적"보다 "배울 게 있는 적"을 고르는 판단**이 재미 포인트.

### 3.4. 인연 (MVP 4명)

| 인물 (오리지널) | 해금 보상 | 인연 엔딩 |
|---|---|---|
| 떠돌이 의원 | 내상 회복 ↑, 독 해독 사건 | 은거 엔딩 |
| 몰락 문파 소문주 | 문파 무공 전수 루트 | 문파 재건 엔딩 |
| 흑도 정보상 | 숨은 사건 위치 공개 | 흑도 지배 엔딩 |
| 강호맹 감찰관 | 대회합 대진 정보 | 정파 엔딩 |

호감도 0~100, 3단계(안면 → 지기 → 생사지교). 생사지교 인물은 **대회합에서 1회 지원**.

### 3.5. 회귀 메타 — 계승 규칙 (로그라이트 축)

| 계승 O | 계승 X |
|---|---|
| 🧩 **기억 조각** — 비밀·단서 플래그 (영구) | 스탯 · 명성 · 호감도 |
| 📖 **전생 무공 1개** (회귀 시 택1, 초식 상태로) | 장착 무공 나머지 |
| 🗝 **기연 해금** — 기억 조각 조합 시 새 사건 개방 | 소지품 |
| 📕 회귀 도감 (발견 인물·무공·엔딩) | — |

**기억 조각 예시**: "3생에서 독살당한 날짜 기억" → 다음 생부터 그 사건에 「전생의 기억」 선택지 등장 → 회피 + 범인 단서.
⚠️ 수치 계승은 최소화 (원작 본질 = 지식 계승). 대신 **회귀 횟수 보너스**는 작게: 회귀 1회당 시작 오성 +1 (상한 +10).

### 3.6. 대회합 (최종전)

| 라운드 | 상대 | 특징 |
|---|---|---|
| 1 | 정파 신진 | 외공 계열 |
| 2 | 사파 고수 | 독 계열 |
| 3 | 세가 후계자 | 내공 계열 |
| 4 | **그림자 맹주** | 전 계열 + 2페이즈. 기억 조각 3개 이상 시 정체 공개 → 약점 개방 |

라운드 사이 회복 없음 (HP 이월 — 본편 `bossChain` 패턴과 동일 사상).

### 3.7. 엔딩 (MVP 5종)

맹주 엔딩 / 인연 엔딩 4종. 엔딩 도달 시 **영구 칭호** + 도감 기록.
