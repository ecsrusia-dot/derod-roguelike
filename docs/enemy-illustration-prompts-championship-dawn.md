## 1. 컨셉 개요 — 천사·빛·심판

dawn 컨셉은 챔피언십 5컨셉 중 **천상·여명·신성** 환경. 클래식 환경과 직접 매칭되는 챕터는 없고 챔피언십 전용 컨셉. 게임 시스템 컨셉은 *심판/신성* — 적이 매 턴 플레이어에게 신성 심판 누적 (저항·해제 메커니즘 별도 설계).

### 1.1. 모든 적 통일 컨셉 (1.58.0)

| 통일 키워드 | 의미 |
|---|---|
| **천사 종족** | 모든 일반/강적/보스는 천사 또는 신적 존재 외형 (인간형 가능, 단 날개·후광 필수). 마족·골렘·정령 X — 컨셉 충돌 |
| **광휘 후광** | 머리 뒤·전신 위로 황금 광채·후광. 일반급은 옅은 후광, 강적은 광휘 띠, 보스는 *거대 후광 + 빛 누설 차원 균열* |
| **신성 룬** | 황금-백색 신성 룬이 갑주·날개 깃털·무기에 새겨짐. frost(얼음)·forest(부패)·sanctum(봉인 보라)·rift(균열 핏빛)와 명확 차별 — **오로지 황금 + 백금 톤** |
| **재질 변주** | 옅은 황금 깃털 (외곽) → 백금 깃털 + 황금 갑주 (성소) → 광휘 차원 깃털 (여명) → 신적 백금 깃털 + 차원 누설 (절대) |

### 1.2. 4단계 환경 톤

| 난이도 | 환경 단계 | 톤 |
|---|---|---|
| **1단계 (천국 외곽)** | **여명의 외곽** | 옅은 황금 하늘, 흩날리는 깃털, 흐릿한 광휘 띠, 부서진 황금 기둥, 발치 떨어진 챔피언 갑주 흔적 |
| **2단계 (천국 성소)** | **여명 성소 회랑** | 황금 신전 회랑, 황금 갑주 + 흰 광휘 띠, 떠 있는 신성 룬 입자, 깨진 광휘 결정 |
| **3단계 (여명 차원)** | **여명 신적 차원** | 깊은 여명 차원, 광휘 띠가 천장에서 늘어짐, 흩날리는 신성 룬 입자, 떠 있는 광휘 결정 |
| **4단계 (신적 여명)** | **여명의 신적 절대 차원** | 신적 여명 차원, 거대 광휘 결정, 황금 차원 균열, 백금 신적 광채, 광휘 사슬이 차원을 가로지름 |

색조는 단계가 올라갈수록: **옅은 황금·하늘색(1단)** → **황금·흰빛 + 신성 룬(2단)** → **광휘 황금·보라빛(3단)** → **백금·신적 황금 + 차원 균열(4단)**. frost(청록·백청), forest(부패 녹·핏빛), sanctum(라벤더·황금 봉인 룬), rift(핏빛-검은-균열)와 명확 차별 — **dawn은 오로지 황금·백금·천상 톤**.

### 1.3. 4보스 차별화 — 4가지 다른 천사 형태

**4보스가 "같은 천사의 색깔 변주"가 되지 않도록**, frost·forest·sanctum·rift 4보스와도 **완전히 다른** 4종으로 분리:

| 보스 | 종족·본체 | 광휘·날개 형태 | 자세·시전 양식 | 무기·도구 |
|---|---|---|---|---|
| **boss1 타락한 견습 천사** | **인간형 비례, 청년 남성**, 황금 갑주, 1쌍 황금 깃털 날개, 머리 위 작은 후광 | 옅은 황금 후광 + 1쌍 날개 | 양손 황금 양손검 휘두름 (역동적 베기 자세, 검사 양식) | **황금 양손검 한 자루** |
| **boss2 거대 세라핌 군주** | **인간형 비례 4배 거대화, 남성**, 백금 갑주 + 황금 룬 갑주, **6날개**(상단 2 + 중단 2 + 하단 2), 거대 후광 띠 | 거대 후광 + 6날개 광휘 | 정적 군림 + 양손 거대 황금 검 들고 위협 (왕좌 위압) | **거대 황금 양손검 한 자루** |
| **boss3 여명의 마녀** | **인간형 비례, 여성 마법사**, 백금 광휘 옷(목~가슴 일체형), 1쌍 광휘 날개, 황금 지팡이 | 광휘 띠 + 1쌍 광휘 날개 | 사방 빛 마법진 동시 시전 (정적 위압, 양손 광휘 마법진) | **황금 지팡이 + 양손 빛 마법진** |
| **boss4 여명의 신** | **인간 비례 X, 신적 스케일** (인간보다 3~4배), 백금 광휘 갑주, **무수한 날개**(8~12쌍이 배경 차원에 흩어짐), 거대 후광 + 차원 균열에서 빛 누설 | 거대 후광 + 무수한 날개 + 차원 빛 누설 | 차원 균열 위로 신적 군림 (정적 신적 압도, 양손 광휘 합장) | **무기 X, 양손 광휘 합장 + 차원 균열 빛 누설** |

차별화 검증 — **청년 검사(1쌍 날개) / 거대 6날개 군주 / 여성 마법사(광휘 옷·지팡이) / 신적 다날개(차원 누설)** — 비례·날개 수·자세·무기 모두 다름. 다른 컨셉과의 교차 검증:

| | dawn | frost | forest | sanctum | rift |
|---|---|---|---|---|---|
| boss1 | **청년 천사 검사** | 인간 전사 | 식물 모성 정령 | 노년 사제 골렘 | 마족 검사 |
| boss2 | **6날개 거대 군주** | 빙거인 | 부패 검왕 | 거대 왕좌 룬 갑주 | 4족 3머리 마수 |
| boss3 | **여성 광휘 마녀** | 사룡 | 광기의 마녀 | 4팔 인형 골렘 | 공중 부유 마족 |
| boss4 | **신적 무수한 날개** | 무형 망령왕 | 광기의 종말 마에스트로 | 거대 신 골렘 | 거대 마왕 |

→ 어떤 보스도 다른 컨셉의 보스와 종족·실루엣·자세가 일치하지 않음.

## 2. 사용법

1. 각 코드 블록을 그대로 복사해 **ChatGPT (DALL-E 3)**에 입력 (1.53.0~ Copilot 폐기, ChatGPT 통일)
2. **반드시 직업 일러 1장을 첨부**해서 화풍 통일도. 권장: `public/classes/sage.jpg` 또는 `public/classes/priest.jpg` (둘 다 황금·신성 톤이라 dawn과 가까움)
3. 한 번에 1~2장 생성 → 마음에 안 들면 같은 채팅에서 "더 OOO하게 다시" 멀티턴 보정 (ChatGPT는 보정 제어가 정확)
4. 다운로드 → `public/enemies/championship/dawn/<enemyKey>_combat.jpg` 또는 `_intro.jpg` 위치에 저장 (placeholder를 덮어쓰기 — 파일명 동일)
5. PM이 main에 푸시 → Claude가 git pull → Pillow로 JPG 변환 후 원본 PNG 삭제

`enemyKey`는 `src/data/enemies.js`의 `ENEMIES` 객체 키와 동일 (예: `champ_dawn_acolyte`). 추후 데이터 통합 시 `chapter: 'dawn_<N>'` 필드만 추가하면 `getEnemyImageSrc` 헬퍼가 자동 라우팅 (CLAUDE.md 5.8절).

