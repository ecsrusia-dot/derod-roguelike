# 황혼 연대기 2.0 — 설계서

> 작성 기준: 1.209.0 · 상태: **PM 검토 대기** (확정 후 PR ①부터 구현)
> 대상: `src/chronicle/` (세 번째 게임 「황혼 연대기」)

## 0. PM 확정 사항

| 항목 | 결정 |
|---|---|
| 기존 저장 | **초기화 + 시작 보상** (2.0은 새로 시작) |
| 캐릭터 진행 | **캐릭터별 따로** (사냥터·던전·이야기는 캐릭터마다, 창고·골드·재료·사역마는 계정 공유) |
| 사역마 수 | **동행 1 + 보조 2** |
| 진행 방식 | **설계서 먼저** → 확정 후 3개 PR 순차 |

## 1. 왜 바꾸나 — 진단

| # | 문제 | 원인 (1.209.0 코드) |
|---|---|---|
| 1 | 주인공 선택이 무의미 | 보스 4명 처치 → 나머지 4직업 **전부 자동 합류** (`companionOrder`). 매 판 같은 5인 조합 |
| 2 | 장비가 공격 위주 | 부위가 옵션을 결정 (`itemStats`: 무기 = 공격 / 갑옷 = 방어·HP / 장신구 = HP·치명·속도). 직업 무관, 누구나 착용 |
| 3 | 최고 등급이 에픽 | 4등급뿐 |
| 4 | 소모가 빠르고 쉬움 | 적 수치를 4인 파티 화력에 맞춤(`area.hpMult` 최대 ×7). PM 실플레이: 사냥터 4곳 + 던전 2곳을 출시 4일 안에 완주. 최대 Lv.40 이후 목표 없음 |

## 2. 전체 구조

```
계정 (공유)
├── 골드 · ✦정수 · ◆파편 · 🗝열쇠 · 📜봉인부
├── 공용 창고 (100칸) — 캐릭터 사이 장비 이동
├── 사역마 보관함 — 포획한 사역마 전부 (어느 캐릭터든 편성 가능)
└── 캐릭터 슬롯 5개 (직업당 1명)
     ├── 레벨 · 능력치 · 스킬 · 마스터리
     ├── 장비 4칸 + 개인 가방 (40칸)
     ├── 사역마 편성: 동행 1 · 보조 2
     └── 진행도: 사냥터 처치 수 · 보스 · 던전 난이도 · 의뢰 · 이야기
```

| 공유 | 캐릭터별 |
|---|---|
| 골드, 정수, 파편, 열쇠, 봉인부, 공용 창고, 사역마 보관함 | 레벨·스탯·스킬, 장비·개인 가방, 사역마 편성, 사냥터·던전 진행, 의뢰·이야기 |

- 첫 캐릭터는 처음부터. **두 번째 캐릭터부터는 공유 자원(골드·창고·사역마) 덕분에 빠르게** 따라잡는다.
- 보스 일일 3회 · 열쇠 일일 충전은 **계정 단위**(캐릭터를 바꿔 가며 무한 파밍 방지).

## 3. 솔로 전투

| 항목 | 지금 | 2.0 |
|---|---|---|
| 아군 | 주인공 + 동료 최대 3 | **주인공 1 + 사역마 동행 1** (보조 2는 패시브만) |
| 적 수치 기준 | 예상 파티 인원 (`area` ×1~×7) | **솔로 + 동행 사역마** 기준으로 전면 재조정 |
| 직업 정체성 | 파티 안에서 역할 분담 | **혼자서 공격·방어·회복을 모두 해야 함** → 직업별 생존 방식이 갈림 |

### 직업별 솔로 생존 방식 (스킬·장비 옵션이 이 방향을 강화)

| 직업 | 공격 | 생존 |
|---|---|---|
| 방랑검사 | 단일 강타·반격 | 높은 방어, **반격**으로 맞으면서 깎음 |
| 술법사 | 광역·지속 피해 | 낮은 HP, **보호막**·재사용 단축으로 버팀 |
| 혼혈 마족 | 연타·광폭 | **흡혈**·높은 HP, 체력이 낮을수록 강해짐 |
| 숲의 정령사 | 연사·치명 | **회피**·속도로 안 맞음 |
| 여명의 사제 | 신성 피해(약함) | **회복·보호막**으로 장기전 |

> 사제는 솔로 화력이 약하므로 「치유량의 일부를 피해로 전환」하는 장비·스킬로 보완 (5절 유니크 참고).

## 4. 장비 — 직업 전용 + 4칸

### 4.1. 장비 칸 (3칸 → 4칸)

| 칸 | 공용 여부 | 기본 능력치 |
|---|---|---|
| 무기 | **직업 전용** | 공격력 |
| 보조 | **직업 전용** | 직업마다 다름 (아래 표) |
| 갑옷 | **직업 전용** | 방어 + HP |
| 장신구 | 공용 | HP + 무작위 1개 |

### 4.2. 직업 전용 장비 이름·보조 칸

| 직업 | 무기 | 보조 칸 (기본 능력치) | 갑옷 |
|---|---|---|---|
| 방랑검사 | 장검 | **방패** (방어·반격 확률) | 판금 |
| 술법사 | 지팡이 | **마도서** (스킬 피해·재사용 단축) | 로브 |
| 혼혈 마족 | 대검 | **혈석** (흡혈·최대 HP) | 흉갑 |
| 숲의 정령사 | 활 | **화살통** (치명·속도) | 가죽 갑옷 |
| 여명의 사제 | 홀 | **성물** (치유량·보호막) | 법의 |

### 4.3. 무작위 옵션 — 직업별 풀

등급이 높을수록 옵션 수가 늘어나고, **옵션은 그 장비 직업의 풀에서만** 뽑힌다 (공격 일변도 해소).

| 직업 | 옵션 풀 (가중치 높은 순) |
|---|---|
| 방랑검사 | 방어 % · 반격 확률 · 반격 피해 % · 받는 피해 감소 · 최대 HP % · 공격력 % |
| 술법사 | 스킬 피해 % · 재사용 단축 · 지속 피해 % · 보호막 % · 치명 피해 % · 공격력 % |
| 혼혈 마족 | 흡혈 % · 최대 HP % · 저체력 피해 % · 공격력 % · 피해 반사 % |
| 숲의 정령사 | 치명 % · 회피 % · 속도 · 추가 타격 확률 · 치명 피해 % |
| 여명의 사제 | 치유량 % · 보호막 % · 받는 피해 감소 · 최대 HP % · 신성 피해(치유량 비례) |
| 장신구 (공용) | 최대 HP % · 공격력 % · 속도 · 경험치 % · 골드 % · 사역마 강화 % |

### 4.4. 등급 5단계 (유니크 추가)

| 등급 | 색 | 무작위 옵션 | 기본 능력치 배율 | 얻는 곳 |
|---|---|---|---|---|
| 일반 | 회색 | 0 | ×1.0 | 사냥터 |
| 고급 | 녹색 | 1 | ×1.2 | 사냥터·강적 |
| 희귀 | 청색 | 2 | ×1.45 | 강적·보스·던전 |
| 에픽 | 보라 | 3 | ×1.8 | 던전 보스·승급 |
| **유니크** | **주황** | **고정 2 + 고유 효과** | ×2.0 | 던전 보스(낮은 확률)·무한 탑 |

- **에픽까지는 대장간 승급 가능, 유니크는 승급 불가** (드랍 전용). 유니크도 강화(+10)는 가능.
- 기존 「에픽 고유 옵션」 12종은 **장신구 에픽 전용 옵션**으로 남김.

### 4.5. 드랍 직업 분배 · 공용 창고

| 항목 | 규칙 |
|---|---|
| 드랍 직업 | **현재 캐릭터 직업 70% · 다른 직업 25% · 공용(장신구) 5%** |
| 다른 직업 장비 | 착용 불가 표시(🔒 직업명) → 분해하거나 **공용 창고로 보냄** |
| 공용 창고 | 100칸, 모든 캐릭터가 꺼내 씀. 다른 직업 캐릭터를 만들면 창고 장비로 바로 무장 |
| 개인 가방 | 캐릭터마다 40칸. 가득 차면 자동 분해(지금과 같음) |
| 일괄 정리 | 「다른 직업 장비 전부 창고로」 버튼 |

## 5. 유니크 장비 — 24종 (1차)

직업당 4개(칸마다 1개) + 공용 장신구 4개. **고정 옵션 2개 + 고유 효과 1개**.

| 직업 | 칸 | 이름 | 고유 효과 |
|---|---|---|---|
| 방랑검사 | 무기 | 눈먼 자의 칼 | 반격이 50% 확률로 2회 연속 |
| | 보조 | 부동의 맹세 | 도발 중 받는 피해 -30% |
| | 갑옷 | 먼지 낀 망토 | 회피·반격 직후 다음 공격 치명 확정 |
| | 장신구 | 스승의 염주 | 전투당 1회, HP 30% 이하가 되면 HP 50% 회복 |
| 술법사 | 무기 | 영겁의 지팡이 | 지속 피해가 2배 길게 지속 |
| | 보조 | 이프리트의 계약서 | 전투 시작 시 「겁화」 자동 시전 |
| | 갑옷 | 재의 로브 | 스킬 사용 시 공격력 20% 보호막 |
| | 장신구 | 시간의 모래시계 | 3턴마다 무작위 스킬 재사용 대기 초기화 |
| 혼혈 마족 | 무기 | 피의 갈망 | 흡혈 15%, 최대 HP를 넘는 회복은 보호막으로 |

| | 갑옷 | 흉터 갑주 | 받은 피해 15% 반사 |
| | 장신구 | 광기의 낙인 | 광폭화 중 모든 공격 2회 |
| 숲의 정령사 | 무기 | 바람의 현 | 「연속 화살」 타수 +2 |
| | 보조 | 정령 화살통 | 공격 시 20% 확률로 정령 화살(공격력 80%) |
| | 갑옷 | 잎새 갑옷 | 회피할 때마다 HP 5% 회복 |
| | 장신구 | 매의 눈 | 치명 피해 +60%, 전투 첫 공격 치명 확정 |
| 여명의 사제 | 무기 | 여명의 홀 | 회복량의 30%만큼 적에게 신성 피해 |
| | 보조 | 순례자의 성배 | 전투당 1회, 쓰러지면 HP 40%로 부활 |
| | 갑옷 | 빛의 법의 | 보호막이 남아 있는 동안 받는 피해 -20% |
| | 장신구 | 축복의 묵주 | 「축복」 효과 2배, 지속 +2턴 |
| 공용 | 장신구 | 황혼의 반지 | 공격력·최대 HP·방어 +8% |
| 공용 | 장신구 | 사역마의 목걸이 | 사역마 피해·HP +30% |
| 공용 | 장신구 | 여행자의 부적 | 경험치 +20% |
| 공용 | 장신구 | 탐욕의 금화 | 골드 +40%, 받는 피해 +10% |

### 유니크 드랍 확률

| 출처 | 일반 | 영웅 | 전설 |
|---|---|---|---|
| 던전 보스 (보상 장비 1개당) | 2% | 5% | 10% |

## 6. 사역마 — 무덤의 유산 방식 이식

### 6.1. 얻는 법 (포획)

| 항목 | 규칙 |
|---|---|
| 대상 | 일러가 있는 적 **54종** (클래식 22 + 챔피언십 서리 16 + 숲 16) |
| 도구 | **📜 봉인부** — 강적·보스 처치 시 드랍, 상점 구매(하루 3장), 의뢰 보상 |
| 시점 | 전투 **승리 결과 화면**에서 「봉인하기」 버튼 (풀오토 전투라 승리 후 선택) — 이번 전투에서 쓰러뜨린 적 중 1마리 |
| 확률 | 등급 기본치 (아래) + 상급 봉인부 +15%p. 실패해도 봉인부 소모 |

### 6.2. 등급 (무덤의 유산과 같은 5단계)

| 등급 | 대상 적 | 기본 포획률 | 최대 레벨 | 한계돌파 |
|---|---|---|---|---|
| 적령 | 사냥터 일반 몹 | 45% | 20 | 1 |
| 녹령 | 사냥터 일반 몹 (낮은 확률로) | 25% | 30 | 2 |
| 청령 | 강적 | 12% | 40 | 3 |
| 남령 | 사냥터 보스 | 6% | 50 | 4 |
| 자령 | 던전 보스 | 2% | 60 | 5 |

- 일반 몹은 포획 시 75% 적령 / 25% 녹령.
- **한계돌파**: 같은 사역마를 또 포획하면 +1돌파 (능력치 +20%/돌파). 최대치 초과분은 정수로 분해.

### 6.3. 편성 — 동행 1 + 보조 2

| 칸 | 개방 | 역할 |
|---|---|---|
| **동행** | Lv.5 | 전투에 직접 참여. 자기 HP가 있고 턴마다 행동 + 고유 스킬 자동 사용. 쓰러져도 다음 전투에 부활 |
| **보조 1** | Lv.20 | 전투 불참, **패시브만** (예: 공격력 +6%) |
| **보조 2** | Lv.40 | 〃 |

### 6.4. 사역마 역할 — 적 종류로 자동 결정

| 역할 | 원본 적 예시 | 동행 행동 | 보조 패시브 |
|---|---|---|---|
| 수호 | 동상 거인 · 깨진 골렘 · 빙하 거인 | 도발 · 방어 | 받는 피해 감소 |
| 맹공 | 얼음 늑대 · 그림자 늑대 · 광기의 호랑이 | 강한 단일 공격 | 공격력 % |
| 주술 | 한기의 마녀 · 봉인 마법사 · 얼음 무당 | 광역 · 지속 피해 | 스킬 피해 % |
| 치유 | 오염된 정령 · 미친 드라이어드 | 주인 회복 | 회복량 % |
| 교란 | 극지의 망령 · 망자의 영혼 | 약화 · 둔화 | 회피 % |

### 6.5. 육성

| 항목 | 규칙 |
|---|---|
| 경험치 | 동행 = 전투 경험치 100%, 보조 = 50% |
| 레벨업 | 능력치 상승 (등급별 성장률) |
| 먹이 | 정수를 먹여 즉시 경험치 (중복 사역마 대체 수단) |
| 공유 | 사역마는 **계정 보관함**에 있고 어느 캐릭터든 편성 가능 (같은 사역마를 두 캐릭터가 동시 편성 불가) |
