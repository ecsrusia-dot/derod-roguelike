## 1. 컨셉 개요 — 골렘에 봉인된 영혼

sanctum 컨셉은 챔피언십 5컨셉 중 **봉인된 신전·신성 룬·봉인** 환경. 클래식 챕터 3(봉인된 신전)과 환경 카테고리는 같지만, 챔피언십은 4난이도 구조라 **각 난이도가 다른 봉인 단계**를 가진다. 게임 시스템 컨셉은 *봉인/제약* — 적이 매 턴 플레이어 스킬을 봉인 (자원 운용·스킬 선택 중요).

### 1.1. 모든 적 통일 컨셉 (PM 1.52.0 결정)

| 통일 키워드 | 의미 |
|---|---|
| **골렘 본체** | 모든 일반/강적/보스는 인형 또는 골렘 외형 (인간형 X). 석조/대리석/금속/룬 갑주 등 재질 변주 |
| **봉인된 영혼** | 골렘 본체 안에 봉인된 영혼이 깃듬. 일반급은 약한 룬 광채만, 강적급은 일부 누설, 보스급은 *영혼이 봉인 풀리듯 골렘 위·뒤로 반투명 솟아오름* |
| **봉인 룬** | 신성 봉인 룬이 골렘 표면·갑주·관절에 새겨짐. 황금-보라 광채 |
| **재질 변주** | 회색 석조 (외곽) → 짙은 보라 신성석 (회랑) → 황금 룬 정교 조각 (심처) → 봉인된 신적 결정 (절대봉인) |

### 1.2. 4단계 환경 톤

| 난이도 | 환경 단계 | 톤 |
|---|---|---|
| **1단계 (외곽 회랑)** | **잊혀진 신전 외곽** | 회색 석조 신전 외곽, 약한 봉인 룬 라벤더 광채, 흐릿한 황금 룬, 부서진 신전 기둥, 봉인된 도전자 시신 흔적 |
| **2단계 (봉인의 회랑)** | **활성 봉인 신전 회랑** | 신전 내부 회랑, 활성화된 봉인 룬 벽, 짙은 보라-신성 광채, 떠 있는 룬 입자, 깨진 봉인 결정 |
| **3단계 (봉인의 심처)** | **봉인 차원 깊이** | 깊은 봉인 차원, 황금 봉인 룬 다발이 천장에서 늘어짐, 흩날리는 룬 입자, 떠 있는 봉인 결정 |
| **4단계 (절대봉인)** | **봉인된 신성 차원** | 봉인된 신성 차원, 거대 봉인 결정, 황금 차원 균열, 신적 광채, 봉인 사슬이 차원을 가로지름 |

색조는 단계가 올라갈수록: **회색 석조 + 옅은 라벤더(1단)** → **짙은 보라 + 활성 룬 광채(2단)** → **황금 + 보라 룬 다발(3단)** → **황금 신적 광채 + 차원 균열(4단)**.

색조는 frost(청록·백청), forest(부패 녹·핏빛)와 명확 차별 — **라벤더·황금 봉인 룬 톤** 고유.

### 1.3. 4보스 차별화 — 4가지 다른 골렘 + 영혼 형태

**4보스가 "같은 봉인 골렘의 색깔 변주"가 되지 않도록**, frost·forest 4보스와도 **완전히 다른** 4종으로 분리:

| 보스 | 골렘 본체 형태 | 봉인된 영혼 형태 (반투명 누설) | 자세·시전 양식 | 무기·도구 |
|---|---|---|---|---|
| **boss1 신전 대사제** | **노년 인간형 황금 정교 조각상 골렘** (정상 비례, 두건·로브 양식 조각) | 노년 인간 **남성 사제 영혼** (반투명 황금-라벤더, 가슴·머리 위로 누설) | 양손 신성 봉인 의식 시전 (정적 의식, 양손 봉인 손마법진) | **봉인 지팡이 + 양손 봉인 손마법진** |
| **boss2 봉인의 군주** | **거대 왕좌 양식 봉인 룬 갑주 골렘** (인간 X, 거대 기계적, 왕관·룬 갑주) | 거대 군주 영혼 (반투명 보라, 왕관 형태, 골렘 **뒤로** 솟아오름) | 거대 룬 망치 휘두름 (운동감 + 왕좌 위압) | **거대 봉인 룬 망치 한 자루** |
| **boss3 심처의 봉인자** | **다중 팔 봉인 룬 인형 골렘** (4팔 인간형, 두건·관절 룬 갑주) | 다중 팔 봉인자 영혼 (반투명 황금, **4팔 영혼이 골렘 4팔 위로 겹쳐** 사방 봉인 룬 시전) | 사방 봉인 룬 동시 시전 (정적 위압, 4팔 사방 펼침) | **무기 X, 4팔 봉인 룬 마법진 사방** |
| **boss4 절대봉인의 군주** | **거대 봉인된 신 골렘** (인간 비례 X, 신적 스케일, 봉인 사슬에 매임) | 거대 신적 영혼 (반투명 황금-신적, **골렘 위로 솟아올라 봉인 차원 누설**, 거대 신적 후광) | 봉인 사슬·봉인 차원에 매여 정적 신적 군림 | **거대 황금 봉인 사슬 + 봉인 차원** |

차별화 검증 — **인간형 조각상 골렘(노년 사제) / 거대 기계 룬 갑주 골렘(왕좌) / 다중 팔 인형 골렘(4팔) / 거대 신적 골렘(신 스케일)** — 종족·실루엣·자세·스케일 모두 다름. frost·forest 어떤 보스와도 겹치지 않음 (frost 인간 전사·빙거인·사룡·망령 / forest 식물 정령·부패 검왕·여성 마법사·남성 마에스트로 / sanctum 골렘+영혼 4종).

## 2. 사용법

1. 각 코드 블록을 그대로 복사해 **ChatGPT (DALL-E 3)**에 입력 (1.53.0~ Copilot 폐기, ChatGPT 통일)
2. **반드시 클래식 챕터 3 일러 1장을 첨부**해서 화풍 통일도 (예: `public/enemies/classic/chapter_3/sealedTemplar_intro.jpg`). 봉인·신성 톤은 챕터 3가 가장 가까움
3. 한 번에 1~2장 생성 → 마음에 안 들면 같은 채팅에서 "더 OOO하게 다시" 멀티턴 보정 (ChatGPT는 보정 제어가 정확)
4. PNG 다운로드 → `public/enemies/championship/sanctum/chapter<N>/<enemyKey>_combat.jpg` 또는 `_intro.jpg` 위치에 저장 (forest 패턴 그대로)
5. PM이 main에 푸시 → Claude가 git pull → Pillow로 JPG 변환 후 원본 PNG 삭제 + 헬퍼 sanctum 분기 추가 PR

`enemyKey`는 `src/data.js`의 `ENEMIES` 객체 키와 동일 (예: `champ_sanctum_acolyte`).
