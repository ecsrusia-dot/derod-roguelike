## 1. 시스템 개요

### 1.1. 두 축의 결합

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│   [각성도]  ──── 영혼/퀘스트로 직업의 기본 강화 (선형)     │
│      │                                                     │
│      ├─ 능력치 (주/보조 스탯)                              │
│      ├─ 시작 패시브 Lv +N                                  │
│      ├─ 주 스테이터스 % (반격율·치명타율 등)              │
│      └─ 각인 슬롯 개방 (Lv.2 / Lv.5 / Lv.9)               │
│                                                            │
│   [각인]    ──── 랜덤 부여 + 가챠로 변경 (확률성)         │
│      │                                                     │
│      ├─ 슬롯 1·2·3 (직업 공통 구조)                       │
│      ├─ 등급별 효과 (C → L)                                │
│      └─ 네거티브 각인 (단점 + 큰 메리트의 트레이드)        │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

### 1.2. 게임 전체 플로우 안에서의 위치

`TitleScreen` → `[영혼의 제단]` 또는 신설 `[직업 각인]` 메뉴 →
직업 선택 → 각성도 강화·각인 슬롯 가챠 → `[원정 시작]`

→ 출정 시 `currentRun.classStats`에 각인 효과가 합산되어 전투에 적용.

## 2. 각성도 시스템 (10단계)

### 2.1. 단계별 보상표 (방랑검사 기준 예시)

| Lv | 영혼 비용 | 누적 | 보상 |
|---|---:|---:|---|
| 1 | — | — | (시작 상태) 기본 능력치 + 시작 패시브 |
| 2 | 500 | 500 | **각인 슬롯 1 개방 → 랜덤 각인 1장 부여** |
| 3 | 1,000 | 1,500 | 주 스탯 +2 (근력 +2) |
| 4 | 2,000 | 3,500 | 시작 패시브 (주) +1Lv (심안류 Lv.3 → Lv.4) |
| 5 | 4,000 | 7,500 | **각인 슬롯 2 개방 → 랜덤 각인 1장 부여** |
| 6 | 8,000 | 15,500 | 보조 스탯 +2 (민첩 +2) |
| 7 | 12,000 | 27,500 | 시작 패시브 (보조) +1Lv (심안 Lv.2 → Lv.3) |
| 8 | 16,000 | 43,500 | 주 스테이터스 +5% (반격율 +5%) |
| 9 | 22,000 | 65,500 | **각인 슬롯 3 개방 → 랜덤 각인 1장 부여** |
| 10 | 30,000 | **95,500** | 능력치 합 +5 (직업별 자동 분배) |

### 2.2. 직업별 보상 매핑

| 직업 | 주 스탯 | 보조 스탯 | 주 패시브 | 보조 패시브 | Lv.8 보너스 |
|---|---|---|---|---|---|
| 방랑검사 (wanderer) | 근력 | 민첩 | 심안류 | 심안 | 반격율 +5% |
| 술법사 (sage) | 마력 | 지능 | 이프리트 | 마력 | 마법 데미지 +5% |
| 혼혈 마족 (demonblood) | 광기 | 근력 | (광기 계열) | (광기 보조) | 광기 게이지 +5% |
| 숲의 정령사 (elf) | 정밀 | 민첩 | (정밀 계열) | (바람 보조) | 회피율 +5% |
| 여명의 사제 (priest) | 신앙 | 지능 | (신앙 계열) | (축복 보조) | 회복량 +5% |

> ⚠️ 술법사~사제는 패시브가 1.21.0 시점에 미정. 각성도 도입 PR에서 시작 패시브 풀을 같이 정해야 함.

### 2.3. 영혼 비용 산정 근거

- **챕터 4 클리어 1회**: 약 50~80 영혼 (보스 20 + 챕터 클리어 20 + 잡몹)
- **챔피언십 hell 1회**: 약 200~300 영혼
- **챔피언십 madness 1회**: 약 400~500 영혼

→ **만렙 95,500 영혼 = 챔피언십 madness 약 200회 + 챕터 4 200회 분량**.
1직업 만렙은 의도된 장기 목표 (전체 5직업 만렙 = ~50만 영혼 → 평생 진행).

### 2.4. 퀘스트 기반 무료 보상 (보조)

영혼 외에 진행 보상으로도 각성도 강화 가능 — 그라인드 의존도 완화.

| 조건 | 보상 |
|---|---|
| 해당 직업 클래식 챕터 4 첫 클리어 | 해당 직업 각성도 +1Lv (무료, 영혼 비용 면제) |
| 해당 직업 챔피언십 normal 첫 클리어 | 해당 직업 각성도 +1Lv |
| 해당 직업 챔피언십 hard 첫 클리어 | 해당 직업 각성도 +1Lv |
| 해당 직업 챔피언십 hell 첫 클리어 | 해당 직업 각성도 +1Lv |
| 해당 직업 챔피언십 madness 첫 클리어 | 해당 직업 각성도 +1Lv |

→ **퀘스트로 최대 +5Lv 무료**. 나머지 5단계는 영혼 구매 또는 추가 챔피언십 클리어 보상.

## 3. 각인 시스템

### 3.1. 슬롯 구조

| 슬롯 | 개방 시점 | 잠금 표시 |
|---|---|---|
| 1 | 각성도 Lv.2 | `???` (회색 자물쇠 아이콘) |
| 2 | 각성도 Lv.5 | `???` |
| 3 | 각성도 Lv.9 | `???` |

3슬롯은 직업 공통. 슬롯 개방 시 풀에서 랜덤 1장 자동 부여 (선택 없음 — PM 안 그대로).

### 3.2. 등급 체계

| 등급 | 색상 | 효과 강도 | 풀 내 비율 (롤 확률) |
|---|---|---|---:|
| Common (C) | 흰 (`#cccccc`) | 작은 능력치 보너스 | 40% |
| Rare (R) | 청 (`#7ba3c4`) | 중간 능력치 + 조건부 트리거 | 30% |
| Epic (E) | 자 (`#9b5fc4`) | 강한 능력치 + 신규 동작 | 20% |
| Legendary (L) | 금 (`#e8b04a`) | 시그니처 (전투 흐름 변경) | 5% |
| Negative — 결함 (-) | 회 (`#777777`) | 작은 페널티 | 3% |
| Negative — 저주 (⚠️/⚖️) | 검 (`#444444`) | 큰 페널티 + 큰 메리트 (트레이드오프) | 2% |

**총합 100%**. 네거티브 5% (결함 3 + 저주 2)는 가챠 재미용. PM이 비율 조정 가능.

### 3.3. 랜덤 알고리즘 (의사 코드)

```js
function rollImprint(pool) {
  const tier = weightedPick({ C: 40, R: 30, E: 20, L: 5, NEG_FLAW: 3, NEG_CURSE: 2 });
  const candidates = pool.filter(i => i.tier === tier);
  return candidates[Math.floor(Math.random() * candidates.length)];
}
```

→ 등급 내 균등 분포. 풀 내 같은 등급 각인이 여러 개면 그 안에서 균등.

## 4. 각인 풀 — 방랑검사 (14개)

방랑검사 컨셉 = **반격 + 회피 + 심안**. 풀은 컨셉 강화 위주.

### 4.1. 포지티브 (10개)

| 등급 | 이름 | 효과 (영구) |
|---|---|---|
| C | 단련된 손목 | 근력 +1 |
| C | 빠른 반응 | 민첩 +1 |
| C | 검사의 끈기 | 시작 HP +10 |
| R | 잔영 | 회피 확률 +5% |
| R | 반격의 손맛 | 반격 데미지 +15% |
| R | 검의 흐름 | 회피 시 영혼 게이지 +3 |
| E | 흘림과 베기 | 회피 시 반격 확률 +20% |
| E | 맹인의 감각 | 적 다음 행동 감지 (심안 Lv.3 효과 영구) |
| E | 영혼의 반향 | 반격 처치 시 영혼 게이지 +15 |
| L | 검의 본능 | 회피 시 자동 반격 (확률 100%, 데미지 ×0.8) |

### 4.2. 네거티브 (4개)

| 등급 | 이름 | 효과 (영구) |
|---|---|---|
| 결함 | 둔한 발 | 회피 확률 -5% |
| 결함 | 무딘 검 | 반격 데미지 -15% |
| ⚠️ 저주 | 시력의 그림자 | 매 턴 시작 회피율 -10% |
| ⚖️ 저주 | 광기의 검 | 반격 데미지 +50% / 받는 데미지 +20% (트레이드오프) |

### 4.3. 컨셉 분포 검증

| 컨셉 축 | C | R | E | L | NEG | 합 |
|---|---:|---:|---:|---:|---:|---:|
| 능력치 (스탯·HP) | 3 | 0 | 0 | 0 | 0 | 3 |
| 회피 강화 | 0 | 1 | 1 | 0 | 1 | 3 |
| 반격 강화 | 0 | 1 | 0 | 1 | 2 | 4 |
| 게이지·자원 | 0 | 1 | 1 | 0 | 0 | 2 |
| 인지·심안 | 0 | 0 | 1 | 0 | 1 | 2 |
| **합** | **3** | **3** | **3** | **1** | **4** | **14** |

→ 모든 등급에 컨셉별로 풀 분산. 가챠 결과가 직업 컨셉 안에서 변주.

## 5. 가챠 시스템

### 5.1. 흐름도

```
[각인 슬롯 1·2·3 화면]
   ↓ PM이 슬롯 1 클릭
[현재 각인: 잔영 (R, 회피 +5%)]
   ↓ [변경하기 (500 영혼)] 버튼
[가챠 애니메이션 1.5초]
   ↓
[결과: 광기의 검 (저주, 반격 +50% / 받는 +20%)]
   ↓
┌────────────────────┬────────────────────┐
│  유지 (기존 잔영)   │  덮어쓰기 (광기의검) │
└────────────────────┴────────────────────┘
```

### 5.2. 비용 표

| 항목 | 비용 (영혼) |
|---|---:|
| 칸별 1회 변경 (기본) | 500 |
| (옵션) 가챠 부적 — C 등급 회피 (Rare 이상 보장) | 1,000 |
| (옵션) 가챠 부적 (대) — Epic 이상 보장 | 3,000 |

PM 결정: 가챠 부적 도입 여부 (없으면 순수 운빨, 있으면 영혼 그라인드로 보장)

### 5.3. UI 디자인 요점

- **롤 결과 모달**에 양 옵션의 효과를 좌우 분할 비교 (현재 vs 신규)
- 등급별 색상 발광 효과 (Legendary는 골든 버스트)
- 네거티브 등장 시 경고 톤 (저주는 진한 검은 배경 + 적색 텍스트)
- "유지" 기본 포커스 (실수 방지)

## 6. 영혼의 제단 통합

### 6.1. 변경되는 항목

| 기존 메뉴 | 변경 | 사유 |
|---|---|---|
| `meta_startSkillLv` (단련된 영혼, 모든 직업 시작 패시브 +1Lv, max 2) | **삭제** | 각성도 Lv.4·Lv.7로 이관. 직업별 개별 강화. |
| `meta_startHp` (강인한 시작 +10 HP, max 20) | **유지** | 직업 무관 공통 |
| `meta_startGold` (풍요의 축복) | **유지** | 직업 무관 공통 |
| `meta_startGem` (명상의 결정) | **유지** | 직업 무관 공통 |
| `meta_maxEther` (에테르의 그릇) | **유지** | 직업 무관 공통 |
| `meta_startRelic` (신탁의 유물) | **유지** | 직업 무관 공통 |
| `meta_dmgDealt` / `meta_dmgTaken` / `meta_critRate` | **유지** | 직업 무관 공통 |
| `meta_chapterHeal` / `meta_rerollDiscount` / `meta_extraReward` | **유지** | 원정 운영 강화 |
| `meta_champion_normal` / `meta_champion_madness` | **유지** | 챔피언십 진행 보상 |

### 6.2. 환불 처리

- `meta.upgrades.meta_startSkillLv` 의 stack 값을 읽어 환불 계산
- stack 1 → 500 영혼 환불
- stack 2 → 500 + 2000 = 2500 영혼 환불
- 환불 후 `meta_startSkillLv` 키 삭제
- 첫 부팅 시 변경사항 모달로 안내 ("단련된 영혼이 직업 각성도 시스템에 통합되었습니다. 영혼 N개가 반환되었습니다.")

// 각인 등급 weighted random
export function rollImprintTier() { /* ... */ }

// 직업의 보유 각인 효과 합산 → 출정 시 currentRun.classStats에 반영
export function getImprintBonus(classId, meta) {
  const slots = meta.awakening?.[classId]?.imprints ?? [];
  const pool = IMPRINTS[classId] ?? [];
  const bonus = { str:0, dex:0, startHp:0, dodgeRate:0, counterDmg:0, /* ... */ };
  for (const impId of slots) {
    if (!impId) continue;
    const imp = pool.find(i => i.id === impId);
    if (!imp) continue;
    Object.entries(imp.effect).forEach(([k, v]) => {
      bonus[k] = (bonus[k] ?? 0) + (typeof v === 'number' ? v : 0);
    });
  }
  return bonus;
}

## 9. 나머지 4직업 각인 풀 가이드라인

각 직업당 14개 (포지티브 10 + 네거티브 4) 목표. 컨셉 분리:

| 직업 | 컨셉 키워드 | 풀 주제 예시 |
|---|---|---|
| 술법사 (sage) | 마법·이프리트·캐스팅 | 마력+, 캐스팅 가속, 이프리트 폭발 보너스, "마나 폭주" 저주 |
| 혼혈 마족 (demonblood) | 광기·자해·폭발 | 광기 게이지+, 처치 시 HP 흡수, "혈식" 저주 (자해+공격력) |
| 숲의 정령사 (elf) | 정밀·바람·다중 타격 | 정밀+, 다중 타격 확률, "바람의 호의" / "잠든 활" |
| 여명의 사제 (priest) | 신앙·축복·회복 | 회복량+, 축복 지속, "맹목적 신앙" 저주 (회복 ↑ / 데미지 ↓) |

각인 작성 원칙:
1. 풀 안에서 직업 컨셉 4~5축으로 분산 (방랑검사: 회피/반격/게이지/인지/스탯)
2. Legendary 1장은 **전투 흐름 변경급** (자동 발동·신규 동작)
3. 네거티브 저주 2장 중 1장은 **트레이드오프** (큰 메리트 + 큰 페널티)
