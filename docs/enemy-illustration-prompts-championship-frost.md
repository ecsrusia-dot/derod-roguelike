# 챔피언십 frost 컨셉 적 일러스트 생성 프롬프트

본 문서는 챔피언십 **frost(서리·동토)** 컨셉 16종 + 보스 진입 풀컷 4종 = **총 20장** 일러스트를 위한 한국어 프롬프트 모음이다.

> 메인 프롬프트 문서: `docs/enemy-illustration-prompts.md` (사용 도구·사이즈·파일 명명·검수 규칙 등 공통 규약 참조)

---

## 1. 컨셉 개요

frost 컨셉은 챔피언십 5컨셉 중 **한기·서리·동토** 환경. 클래식 챕터 1(북부 극지대)과 환경 카테고리는 같지만, 챔피언십은 4난이도 구조라 **각 난이도가 다른 환경 단계**를 가진다.

| 난이도 | 환경 단계 | 톤 |
|---|---|---|
| **1단계 (입문)** | **동토 황무지** | 황혼의 영구동토, 가벼운 눈보라, 보라-녹색 오로라 — 클래식 챕터 1과 같은 야외 동토 |
| **2단계 (얼음 동굴)** | **빙하 동굴 내부** | 깊은 동굴, 천장 얼음 종유석 + 바닥 석순, 청록 어둠 발광, 동굴 벽 옛 한기 룬 |
| **3단계 (빙하 협곡)** | **거대 빙벽 협곡** | 양쪽에 우뚝 솟은 푸른 빙벽, 협곡 바닥, 상공 한기 돌풍, 멀리 한기룡 둥지 흔적 |
| **4단계 (절대영도)** | **시간이 멈춘 옥좌** | 공중에 정지된 눈 입자가 별처럼 떠 있는 광활한 백청색 무한공간, 절대 정적, 시네마틱 스케일 |

색조는 단계가 올라갈수록 점진 변화: **창백한 청록·은회색(1단)** → **짙은 청록·암청색(2단)** → **빙하 청·강한 청록(3단)** → **백청·은백·별빛 청록(4단)**.

### 4보스 차별화 (1.18.0 재설계)

**4보스가 "같은 인물의 색깔만 다른 변주"가 되지 않도록**, 4가지 완전히 다른 존재 형태로 분리:

| 보스 | 존재 형태 | 자세 카테고리 | 무기·전투 양식 |
|---|---|---|---|
| **boss1 눈보라의 군주** | **인간 광폭 전사 정복자** | 도약 광폭 일격 (수평 운동감) | 거대 양손검 한 자루, 손마법 X |
| **boss2 동굴의 빙왕** | **거대 빙거인** (인간 X) | 거대 망치 머리 위 강타 (수직 압도감) | 거대 양손 망치, 손마법 X |
| **boss3 협곡의 한기룡** | **거대 사룡 (협곡 매달림)** | 협곡 빙벽 사이 발톱 매달림, 머리 하강 (공중·하강 위협) | 발톱·숨결, 무기 X |
| **boss4 절대영도의 군주** | **무형 반투명 망령왕** (인간 X) | 옥좌 위 반쯤 떠 있는 정지 (정적 위압) | 시간 정지 그 자체, 무기 X |

→ **인간 전사 / 거대 거인 / 사룡 / 무형 망령** — 종족·실루엣·자세·무기 모두 다름.

## 2. 사용법

1. 각 코드 블록을 그대로 복사해 **Microsoft Copilot Designer**에 입력
2. **반드시 클래식 챕터 1·4 일러 1장을 첨부**해서 화풍 통일도 (예: `public/enemies/classic/chapter_1/iceMage_intro.jpg` 또는 `public/enemies/classic/chapter_4/nakzelionShadow_intro.jpg`)
3. 결과 4장 중 가장 잘 나온 1장 선택. 마음에 안 들면 같은 채팅에서 "더 OOO하게 다시" 멀티턴 보정
4. PNG 다운로드 → `public/enemies/championship/frost/<enemyKey>_combat.jpg` 또는 `_intro.jpg` 위치에 저장
5. PM이 main에 푸시 → Claude가 git pull → Pillow로 JPG 변환 후 원본 PNG 삭제

`enemyKey`는 `src/data.js`의 `ENEMIES` 객체 키와 동일 (예: `champ_frost_imp`).

## 3. frost_1 — 동토 황무지 (입문, 5종 + 보스 진입 1종)

배경 톤: **황혼의 동토 황무지 + 얼음 절벽 + 가벼운 눈보라 + 보라-녹색 오로라 하늘 + 갈라진 영구동토 + 멀리 빙하 능선 + 눈에 묻힌 도전자 흔적**. 챔피언십 입문급이라 클래식 챕터 1과 비슷한 야외 동토 톤이지만, 도전자의 시신·부서진 챔피언십 깃발 등으로 *경연장* 느낌 추가.
