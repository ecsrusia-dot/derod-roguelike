## 1. 한 줄 요약

**시즌계에서 1주일 동안 키우고 → 시즌이 끝나면 캐릭터가 승천 → 승천계에서는 키우지 않고, 모은 승천 캐릭터로 신에게 도전한다.**

---

## 2. PM 확정 사항

| 항목 | 결정 |
|---|---|
| 서버 구분 | **시즌계**(육성·경쟁) / **승천계**(결과물 도전) |
| 시즌 길이 | **1주** (월요일 0시 교체, 한국 시간) |
| 시즌 시작 상태 | 캐릭터 Lv.1 · 재화·사역마·창고 **전부 0** + 시즌 가속 |
| 원정대 레벨 상한 | 시즌계에서는 **해제** |
| 승천계 레벨링 | **없음** — 승천 시점 상태로 고정 |
| 갈래별 저장 | 갈래마다 따로 보관 (같은 갈래는 강한 쪽만) |
| 시즌 캐릭터 수 | **제한 없음**, 전승한 캐릭터는 전부 승천 |
| 보상의 쓰임 | 다음 시즌 시작 특전 + 칭호 + **승천 특성**(승천계 보상으로 찍는 영구 특성 — 시즌계에 이로운 효과: 공격 강화·경험치 증가 등). 승천 캐릭터 자체는 강해지지 않음 |
| 시즌 가속 | **경험치 ×1.5** |
| 승천 상태 | **전승 직전 상태 자동 보관** — 후보와 현재 상태 중 강한 쪽이 승천 |
| 첫 시즌 시작 | **PM이 「시즌제 시작」 버튼을 누를 때** (그다음 월요일부터) |
| 원정대 「다섯 봉인」 레이드 | 시즌계에서 없애고 **신 토벌로 대체** |
| 기존 캐릭터 | **첫 시즌 시작 전까지 더 키운 뒤** 「시즌 0」으로 승천 |
| 경쟁자 | 같은 방식 — 매 시즌 승천시키고 승천계 순위에도 참가 |

## 3. 두 서버

| | 시즌계 | 승천계 |
|---|---|---|
| 하는 일 | 사냥·던전·첨탑·투기장 (지금 게임 그대로) | 신 토벌 (5인 파티) |
| 순위 | **시즌 순위** — 매주 확정 후 초기화 | **승천 순위** — 누적 |
| 재화 | 골드·정수·조각 등 (시즌마다 0) | 승천 인장 (시즌 특전 구매용) |
| 캐릭터 | 직업당 1명 (최대 5명) | 갈래당 1칸 (최대 10칸) |

### 3.1. 주간 흐름

| 요일 | 일어나는 일 |
|---|---|
| 월 0시 | 새 시즌 시작. 시작 특전 적용 |
| 월~일 | 육성 · 시즌 순위 경쟁 · 투기장 |
| 일 24시 | 순위 확정 → 보상 → 전승한 캐릭터 승천 → 시즌계 초기화 |
| 언제든 | 승천계에서 신 토벌 도전 |

접속하지 않은 채 주가 바뀌면, 다음 접속 때 지난 시즌을 정산한 뒤 새 시즌을 시작한다.

## 4. 1주일 성장 실측

`node scripts/sim-chronicle-season.mjs` — 빈 계정에서 캐릭터 1명만 키우는 봇 (사역마는 얻은 조각으로 소환, 강화 +7까지, 조건이 되면 즉시 전승).

### 4.1. 전승 도달 전투 수 (5직업 범위)

| 전승 | 가속 없음 | 가속 ×1.5 (술법사) | 가속 ×2 (검사·술법사) |
|---|---|---|---|
| 1회 | 2,650 ~ 2,950전 | 1,985전 | 1,420 ~ 1,520전 |
| 2회 | 6,300 ~ 6,800전 | 4,542전 | 3,320 ~ 3,380전 |
| 3회 | 11,600 ~ 12,300전 | 8,074전 | 6,130 ~ 6,170전 |
| 4회 | 18,800 ~ 19,700전 | 13,040전 | 9,800전 |
| 5회 | 25,000전 안에 미도달 | 19,000전 안에 미도달 | 14,170 ~ 14,550전 |

### 4.2. 하루 플레이량별 1주 도달 지점

| 하루 전투 | 1주 합계 | 가속 없음 | 가속 ×1.5 | 가속 ×2 |
|---|---|---|---|---|
| 1,000전 | 7,000전 | 전승 2회 직후 (Lv.34~67) | 전승 2회 Lv.116 | 전승 3회 Lv.102 |
| 2,000전 | 14,000전 | 전승 3회 Lv.102~106 | 전승 4회 Lv.101 | 전승 4회 Lv.141~147 |
| 2,700전 (PM 속도) | 19,000전 | 전승 3~4회 | 전승 4회 Lv.147 | 전승 5회 Lv.142~151 |

- 사냥 승률 99~100% (레벨에 맞는 자리에서 사냥)
- 동행 사역마: 약 3,500전에 남령, 7,000~14,000전에 자령 +10
- 측정하지 않은 것: 여러 직업을 같이 키울 때, 던전·첨탑을 섞을 때, 가속 ×1.5의 다른 직업

## 5. 승천

### 5.1. 규칙

| 항목 | 내용 |
|---|---|
| 조건 | 전승 1회 이상 (갈래가 있어야 칸이 정해짐) |
| 보관되는 것 | 레벨·전승 횟수·능력치 배분·스킬·특성·특전 · 착용 장비 4부위 · 편성 사역마(동행+보조) · 그 시즌 사역마 보유 목록(보유 효과·인연 계산용) |
| 보관 칸 | 갈래 10칸 |
| 같은 갈래가 이미 있으면 | 「승천 전투력」이 높은 쪽만 남김 |
| 전승 못 한 캐릭터 | 승천하지 않고 기록(직업·레벨)만 남김 |
| 남은 재화·미착용 장비·남은 사역마 | 일부를 승천 인장으로 환산 (합계 상한 200 — `season.js` `SEASON.convert*`) 후 사라짐 |

### 5.2. 전승 직전 상태 보관 (확정 · 1.295.0 구현)

전승하면 Lv.1로 돌아가므로, 전승할 때마다 직전 상태를 그 캐릭터의 「후보」로 저장한다(더 강한 후보만 남김). 시즌 종료 때 후보와 현재 상태 중 승천 전투력이 높은 쪽이 승천한다.

### 5.3. 승천 전투력

같은 갈래끼리 비교할 때 쓰는 숫자. 고정된 훈련 상대(Lv.120 보스형, 체력 매우 큼)에게 **준 피해 ÷ 1,000** — 같은 난수 3회 평균. 오래 버틸수록 많이 때리므로 생존력도 반영된다. (`ascend.js` `ASCEND` · `ascPower`)

## 6. 승천계 — 신 토벌

| 항목 | 내용 |
|---|---|
| 파티 | 승천 캐릭터 5명 (갈래 중복 불가). 5명 미만이어도 도전 가능 |
| 상대 | 신 1체. 단계가 끝없이 오르며 체력·공격이 커짐 |
| 점수 | 격파한 최고 단계 + 다음 단계에서 깎은 체력 비율 |
| 주간 약점 | 시즌마다 바뀜 (예: 지속 피해 +50% / 단일 공격 +50% / 회복 무효) → 갈래를 고르게 모을 이유 |
| 도전 횟수 | 하루 3회 (점수는 최고 기록) |
| 전투 | 풀오토 관전. 기존 원정대 레이드 전투 방식을 재사용 |
| 보상 | 승천 순위에 따라 주간 승천 인장 + 칭호 |

## 7. 순위와 보상

| 순위 | 기준 | 확정 | 보상 |
|---|---|---|---|
| 시즌 순위 | 그 시즌의 성장 점수 (전승·레벨·첨탑) | 매주 | 승천 인장 + 순위 칭호 |
| 시즌 투기장 | 그 시즌의 투기장 점수 | 매주 | 승천 인장 |
| 승천 순위 | 신 토벌 최고 점수 | 누적 (주간 보상) | 승천 인장 + 칭호 |

### 7.1. 승천 인장으로 사는 시즌 시작 특전 (예시)

| 특전 | 효과 |
|---|---|
| 계약서 꾸러미 | 시작할 때 계약서 조각 100 |
| 열쇠 꾸러미 | 시작 열쇠 +5 |
| 가속 이용권 | ×4 배속 3시간 |
| 여비 | 시작 골드 |
| 청령의 인도 | 첫 소환 청령 이상 확정 |

특전은 **다음 시즌 출발만** 돕는다. 승천 캐릭터의 능력치는 바뀌지 않는다.

### 7.2. 승천 특성 (PM 추가 결정)

승천계 보상(신 토벌·승천 순위)으로 얻는 재화로 찍는 **계정 영구 특성**. 시즌이 바뀌어도 남고, **시즌계 캐릭터에게만** 적용된다.

| 예시 | 효과 |
|---|---|
| 승천자의 힘 | 시즌계 공격력 +N% |
| 승천자의 가르침 | 시즌계 경험치 +N% |
| 승천자의 인도 | 시즌계 사역혼·조각 획득 +N% |
| 승천자의 가호 | 시즌계 최대 HP +N% |

수치·단계·비용은 PR ④에서 시뮬(`sim-chronicle-season.mjs`)로 정한다. 시즌이 지날수록 출발이 빨라지는 장기 성장 축이 된다.

기존 「주간 순위 보상」「월간 1위 자령 선택」은 폐지하고 위 구조로 옮긴다.

## 10. 저장 구조

| 위치 | 내용 |
|---|---|
| 계정 최상위 (지금 구조 그대로) | **시즌계** — 캐릭터·재화·창고·사역마 |
| `acc.seasonKey` | 이 시즌의 주(월요일 날짜) |
| `acc.asc` | **승천계** — `slots{갈래: 스냅샷}` · `log[시즌별 기록]` · `god{최고 점수·오늘 도전 수}` · `seal`(승천 인장) · `titles` · `perks`(다음 시즌 특전) · `rivals{경쟁자 승천 상태}` · `storySeen` |

- 시즌 교체 = 정산 → 스냅샷 생성 → 최상위를 새 계정으로 교체하고 `asc`·설정만 옮김
- 전투 엔진·화면은 최상위 구조가 그대로라 대부분 수정 없이 동작
- 스냅샷은 원본 데이터(능력치 배분·장비·사역마)를 저장하고 전투 때 다시 계산 — 나중에 밸런스를 바꿔도 반영됨

## 11. 기존 캐릭터 이관 (「시즌 0」)

| 단계 | 내용 |
|---|---|
| 유예 기간 | 기한 없음 — PM이 승천계 화면의 「시즌제 시작」 버튼을 누르면 그다음 월요일 0시에 시즌 1 시작 |
| 시즌 1 시작 | 전승한 캐릭터는 승천계로, 전승 못 한 캐릭터는 기록으로 |
| 사역마·재화·창고 | 시즌 1로 가져가지 않음 |
| 안전장치 | 이관 직전 상태를 백업 칸에 보관 |

PM 저장 기준: 대마도사(전승 1회 Lv.105)만 승천 가능. 나머지 4명은 유예 기간에 전승하면 승천.

## 13. 위험과 미정 사항
