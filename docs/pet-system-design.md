## 0. 확정 사항 (PM 결정 이력 — 4차까지)

| # | 결정 | 내용 |
|---|---|---|
| 1 | 컨셉 | 괴이(원혼)를 제령해 부하로 사역. 등급 5단계: **적령 · 녹령 · 청령 · 남령 · 자령** |
| 2 | 운용 | **동행 1체** — 패시브 + 액티브(자동) |
| 3 | 수문장 | 남령·자령 = 수문장급 포함, **묘주까지 제령 가능**. 제령해도 수문장은 계속 등장 |
| 4 | **제령부 드랍 (4차)** | 보스 처치 시 **제령부 자체 드랍율 10% 고정** → 그 안에서 등급 배분 **적 60 / 녹 25 / 청 9 / 남 5 / 자 1%**. **드랍처는 모든 보스**. 드랍율·등급 배분 모두 **보상 증가 버프(드랍 운 등) 영향 없음** |
| 5 | **소유 제한 (4차)** | 제령부 보유 상한 **적 10 / 녹 5 / 청 3 / 남 2 / 자 1**. 초과 획득분은 먼지로 자동 분해. **런 한정** — 사망 시 초기화, 해당 런에서만 획득·사용 (char 저장, meta 아님) |
| 6 | 제령 조건 | **HP 25% 이하** + 해당 등급 제령부 1장. 성공률 = 기본치 + (25 − HP%) × 0.5%p. 기본치 **적 45 / 녹 25 / 청 12 / 남 6 / 자 2%** (✅ 승인) |
| 7 | **실패 페널티 (4차)** | 제령부 소진 + **턴 소모** + **적 광포화**([격노] 부여) + **그 전투에서 추가 제령 불가** |
| 8 | **한계돌파 (4차)** | 제령된 괴이는 재제령 기본 불가. 단 **이번 런에 동행 중인 괴이와 동일 개체** 제령 성공 시 한계돌파 → 능력치 업그레이드. 횟수 상한: **적 1 / 녹 2 / 청 3 / 남 4 / 자 5회**. 돌파 효과는 스킬 확정 후 결정 (아래 8절 제안) |
| 9 | **능력 구조 (4차)** | 스테이터스 대신 **패시브 스킬 + 액티브 스킬**. 물리·기교·마법 밸런스 배분 + 사냥 외(탐사·경제) 패시브 일부. **액티브 = 내 턴 종료 시 자동 발동, 적 행동보다 우선** |

## 1. 제령부 드랍 흐름 (확정 수치)

```
보스 처치 → 10% 판정 (버프 무관) → 당첨 시 등급 굴림 (버프 무관)
  적령부 60% · 녹령부 25% · 청령부 9% · 남령부 5% · 자령부 1%
→ 보유 상한 초과면 먼지로 분해
```
- 실효 드랍율: 보스 1마리당 자령부 **0.1%** (10% × 1%) — PM 2차 지정치와 일치. 청령부 0.9%, 남령부 0.5%
- 사망 시 제령부 전량 소멸 (런 한정 소모품)
