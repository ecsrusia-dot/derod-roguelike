## 0. 확정 사항 (PM 결정 이력)

| 결정 | 내용 | 시점 |
|---|---|---|
| 컨셉 | 펫 아님 — **괴이(원혼)를 제령해 부하로 사역** | 2차 |
| 등급 | 원작 7단계 → **5단계 축소**: 적령(적+주 통합) · 녹령(황+녹 통합) · 청령 · 남령 · 자령 | **3차** |
| 운용 | **동행 1체** — 패시브 + N턴마다 자동 개입기 | 3차 |
| 수문장 | **남령·자령 = 수문장급 포함** — 묘주까지 제령 가능 (「전설 포켓몬」 포지션). 제령해도 수문장은 계속 등장 (원혼의 본체는 무덤에 남는다는 설정) | 3차 |
| 제령 조건 | **HP 25% 이하** + 해당 등급 제령부 1장 소모. HP 1%p 낮아질 때마다 성공률 **+0.5%p** | 2차 (PM 지정) |
| 제령부 드랍율 | 보스 드랍 — **청령부 5% / 남령부 1% / 자령부 0.1%** (PM 지정) | 2차 (PM 지정) |
| 구현 | **보류 — 문서만 갱신, 다음 검토 대기** | 3차 |

## 1. 등급 체계 (5단계 — 원작 설정 유지, 게임 단계만 통합)

| 등급 | 통합 전 | 설정 | 게임 내 대응 |
|---|---|---|---|
| 적령(赤靈) | 적+주 | 지박령~빙의. 오한·몸살 수준 | 표층~중층 일반 |
| 녹령(綠靈) | 황+녹 | **살(殺)**~수십 년. 죽음에 이르게 하고 사물을 움직인다 | 심층 일반·강적 |
| 청령(靑靈) | — | 백 년+. 환각 — 이매망량의 영역 | 강적 최상위·보스 |
| 남령(藍靈) | — | 삼백 년+. 영력 실체화, 마수급 | **수문장 하위** |
| 자령(紫靈) | — | 오백 년+. 일반 수단으로 제령 불가 | **수문장 최상위·묘주** |

## 2. 적 일러 등급 분류 초안 (기존 적 26종 — 일러 그대로 재사용)

| 등급 | 배정 괴이 |
|---|---|
| 적령 (8) | 통곡하는 원혼 · 창백한 원혼 · 모래 위습 · 동상 그림자 · 묘지 망령 · 땅거미 아이 · 거울 환영 · 그림자 잠복자 |
| 녹령 (8) | 썩은 정령 · 리치의 사도 · 밤의 잠복자 · 봉인 사제 · 황혼의 잔재 · 서리 귀환자 · 익사한 기사 · 망각의 간수 |
| 청령 (4) | 몽마 여왕 · 역병의 마녀 · 봉인의 마녀 · 카토블레파스 |
| 남령 (3) | 무덤의 폭군 · 수문장 망령왕 · 수문장 마에스트로 |
| 자령 (3) | 수문장 낙젤리온 · 태초의 포식자 · **묘주** |

## 4. 제령 성공률 (PM 공식)

- **HP 25% 이하**에서만 시도 가능, 제령부 1장 소모 (실패해도 소모 — 다음 검토 ❓)
- 성공률 = 등급별 기본치 + (25 − 현재 HP%) × 0.5%p

| 등급 | 기본 (HP 25%) | HP 10% | HP 1% (최대) |
|---|---|---|---|
| 적령 | **45%** (제안) | 52.5% | 57% |
| 녹령 | **25%** (제안) | 32.5% | 37% |
| 청령 | **12%** (제안) | 19.5% | 24% |
| 남령 | **6%** (제안) | 13.5% | 18% |
| 자령 | **2%** (제안) | 9.5% | **14%** |

- 실패 시: 전투 계속 (턴 소모? — 다음 검토 ❓)

## 5. 사역 — 동행 1체 (확정)

- 제령한 괴이는 로비 **「사역각(使役閣)」**에 영구 소장 — 도감(미제령은 실루엣)
- 출정 시 **1체 동행**: 등급 비례 패시브 fx + **N턴마다 자동 개입기** (턴 미소모)
- 개입기 예시 (초안): 적령 — 4턴마다 적 [약화] 1 / 녹령 — 4턴마다 도트 부여 / 청령 — 3턴마다 [혼란]·환각 / 남령 — 3턴마다 방벽 1 / 자령(묘주) — 3턴마다 마력 대타격 + 흡수
- 성장: 함께 전투한 횟수로 Lv (상한 10) → fx 수치 상승
- 사망·이탈 리스크 없음 — 계정 영구 (다음 검토 ❓)
