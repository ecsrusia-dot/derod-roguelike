## 1. 컨셉 — 「무덤의 짐승들」

무덤 깊은 곳에는 마물이 아닌 **짐승**들이 산다. 길들이면 함께 내려가 준다.
핵심 재미는 **전설 짐승 사냥**: 흔적을 모으고, 서식지를 계시받고, 직접 찾아가 제압해 포획한다.

## 2. 전설 사냥 루프 (핵심 — 포켓몬 레전드 모티브)

| 단계 | 내용 |
|---|---|
| ① 흔적 발견 | 심층 탐사 중 확률 발견 — 이벤트 방 결과·전투 승리 후·야영 중. 전설당 흔적 3개 (예: "거대한 발자국", "얼어붙은 깃털", "울음소리의 메아리") |
| ② 서식지 계시 | 흔적 3개를 모으면 서식 조건 공개 — 예: **"명계의 문턱(200~299층), 붉은 이름의 방"**. 층은 매 런 무작위가 아니라 조건 매칭 (도달 가능한 목표) |
| ③ 조우전 | 조건 층 진입 시 강제 조우 — **재앙급 초강력**. 죽이면 실패 (흔적 1개부터 다시) |
| ④ 제압 포획 | HP **25% 이하**로 만들면 「길들이기」 행동 해금 — 성공률 = (25 - 남은HP%) × 4 정도. 실패 시 짐승 도주 → 흔적 1개 재수집 |

### 전설 짐승 5종 (대역 1:1 — 1.143.0 대역 시스템 연계)

| 대역 | 전설 (가칭) | 컨셉 | 동행 효과 방향 |
|---|---|---|---|
| 망각의 회랑 (100~) | 회랑의 흰 늑대 | 최초의 길잡이 | 회피·선제 |
| 명계의 문턱 (200~) | 나루터의 검은 소 | 망자를 건네는 짐승 | 방벽·수호 |
| 태초의 어둠 (300~) | 빛을 삼킨 뱀 | 어둠 그 자체 | 흡혈·저주 |
| 무덤의 근원 (400~) | 뿌리 밑의 두더지왕 | 무덤을 판 장본인 | 먼지·드랍 |
| 정점 너머 (500~) | **묘주의 옛 친구** | 묘주 격파 후에만 흔적 등장 (엔드 연계) | 전 능력 소폭 + 고유기 |

## 3. 일반 팻

- 짐승형 몬스터 약 20종 포획 가능 (늑대·거미·와이번·게·살무사 등 — 기존 80종에서 선별)
- 전투 승리 시 낮은 확률 「영혼 낙인」 획득 → 낙인으로 길들임 (전설과 달리 제압 불필요)
- 성능은 전설 대비 소박 — 수집·도감 재미 중심

## 4. 동행 효과 (전투)

- **1마리 동행** (로비에서 선택)
- 패시브 fx (기존 어휘: physPct/dodge/healPct/dropLuck 등 — 소비 지점 재사용, 전투 코드 최소)
- **개입 스킬 1개**: N턴마다 자동 발동, 턴 미소모 (예: 흰 늑대 — 3턴마다 [잔영] 1 부여)
- 성장: 함께 전투한 횟수로 레벨 → fx 수치 상승 (상한 Lv.10)
- 사망 페널티 없음 (팻은 죽지 않고 계정 영구 — 로그라이크 상실감과 분리, PM 확인 필요 ❓)

## 5. 관리 화면 — 로비 「우리(축사)」

- 보유 팻 목록·동행 선택·팻 도감 (미발견 실루엣)
- 2차 확장 후보: BB2 배양(培養Incubator) 시트로 팻 부위 강화
